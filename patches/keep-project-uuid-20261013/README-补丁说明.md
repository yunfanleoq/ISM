# 项目 ID 热修（2026-10-13）

修大屏右上角齿轮进后台后弹出「项目ID错误」、数据仓库左侧设备树空白。

原因：打开「我的项目」时，项目列表请求会把浏览器里已经保存的项目 ID 删掉。大屏接口在白名单里，所以登录和大屏仍然正常；数据仓库不在白名单里，项目 ID 没了就弹错、树是空的。

## 这个包做什么

只在现有前端页面末尾挂一段小脚本：项目列表、新增、编辑、删除这些请求仍然不带项目 ID 请求头，但不再清除已经保存的项目 ID。登录时仍会清除。

## 这个包不做什么

- 不替换 `ism_server`
- 不覆盖上次的画面热修（导航、弹窗、测点卡片）
- 不重启服务
- 不改数据库、地图、上传文件、密码

## 安装

把本目录解压后执行（主包目录按现场实际，若是 `20260708` 就换成那个）：

```bash
bash apply-keep-project-uuid.sh /opt/ISM/ism-release-oceanbase-20260709
```

脚本会备份 `index.html`，写入 `static/js/ism-keep-project-uuid.js`，并在 `</body>` 前引用它。重复执行不会插两遍。

然后浏览器 **Ctrl+F5**。如果当前已经停在空白的数据仓库，先回大屏，再点一次右上角齿轮。

## 应用管理里「设计」点不了

「设计 / 授权 / 分享 / 编辑 / 删除」点不了、只有「运行」能点，不是这个包造成的。这几个按钮要求角色具备编辑（删除还要删除权限）。没有权限时按钮会被禁用，鼠标停在「设计」上会提示「无此权限」。

管理员、操作员默认权限是 `add,edit,delete,view`。普通用户只有 `view`，只能运行。要用带编辑权限的账号，或给该角色加上编辑、删除后再重新登录。
