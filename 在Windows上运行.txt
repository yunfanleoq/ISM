这是寻智机房动环的源码，给另一台装了 Cursor 的 Windows 电脑用。

1. 把优盘里的「ISM源码-xunzhi-jf」整个文件夹复制到本机硬盘，例如 D:\ISM源码-xunzhi-jf。
   不要在优盘上直接编译，FAT32 又慢又容易把依赖写坏。
2. 用 Cursor 打开复制后的文件夹。
3. 本机需要先装好 Node.js 20 或更高，并加入 PATH。
   后端已经带了编好的 ism_server.exe（64 位 Windows），不用再装 Go。
   只有 exe 丢失时，才需要 Go 1.22 和 MinGW-w64 的 gcc 重新编译。
4. 双击 start-xunzhi-windows.bat。
   第一次会 npm install，再启动前端。前端第一次编译要几分钟。
5. 打开 http://127.0.0.1:7081 ，账号 admin，密码 123456。
   后端端口是 8082。本体页是 /#/xunzhi/jf/ontology ，智能体页是 /#/xunzhi/jf/agent。

包里已经带上当前的 SQLite 库 ism_server_user\data\db\ism.db，以及 Go vendor。
没有带 Mac 的 node_modules 和 Mac 可执行文件，那些在 Windows 上不能用。
配置里的数据库类型是 SQLite（app.conf 的 dbtype=1），不需要再装 MySQL。
