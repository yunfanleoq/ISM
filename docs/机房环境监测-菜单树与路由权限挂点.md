# 机房环境监测 · 菜单树与路由/权限挂点

> **版本**：v1.0 · 2026-10-12（Asia/Shanghai）  
> **用途**：用户当场要求——资产等入口挂进菜单；同窗全量模块均须有菜单入口，不能只剩动环平面。供研发按此实现。  
> **对齐**：架构契约 v2.0 §2 / §4 / §9 RBAC  
> **权威契约**：`/workspace/寻智科技/docs/机房环境监测-ISM增量架构契约.md`  
> **硬约束**：ISM 增量（Ant Design Vue）；禁止 SpringBoot；不编金额；等保测评未标明

---

## 1. 实现原则

| # | 原则 |
|---|------|
| 1 | **同窗全量可见**：监测/告警/可视化/资产/容量/工单/能耗/安防消防/系统（权限）均有一级或二级菜单；无入口 = 缺陷 |
| 2 | **按子模块挂菜单**：菜单 `module` 字段 = 契约代号（`dcim-asset` 等）；前端路由懒加载对应包 |
| 3 | **菜单 ≠ 授权**：菜单显示仍须 `permission` + 数据范围；无权限则隐藏或进页 403 |
| 4 | **演示优先**：S0/S1 相关菜单（监测实时、平面大屏、告警）置顶且默认对 `R1`+ 可见 |
| 5 | **路径前缀**：前端 `/xunzhi/jf/...`；API `/api/xunzhi/jf/...`（与契约 §4 一致；若 ISM 现网惯例不同，研发可映射一层，但权限码不变） |
| 6 | **同一壳**：挂进 ISM 现有主布局侧栏/顶栏；不新建 Bootstrap 壳 |

## 6. 研发落地顺序（不挡演示）

| 序 | 动作 | 验收可见 |
|----|------|----------|
| A | 侧栏挂上 **全部分组**（可先全部链到占位页） | 用户能看到资产/容量/工单/能耗等入口 |
| B | 接通 S0/S1 真页：监测实时、平面大屏、活动告警 | 演示主路径 |
| C | 接通资产总览+空间树最小页（读共享树 / `dcim-asset` 骨架） | 「资产已进菜单且可点」 |
| D | 其余按里程碑 S2–S6 换真页，**不删菜单** | 同窗全量入口不回退 |

**打回**：删掉资产等菜单「等二期再挂」；只留动环平面；SpringBoot 新壳。
