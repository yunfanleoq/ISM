## 阻塞：登录 1003（Mac 掉线未在本机闭环）

| 项 | 现象 |
|----|------|
| API | `POST http://127.0.0.1:8082/login`，`admin` + MD5(`123456`) → **`code: 1003`** 用户不存在 |
| 影响 | 无法重新登录 → `/xunzhi/jf/*` 动态路由未挂载 → **三红 UI**（大屏 / plane / HomeDashboard）无法在本轮目视验收 |
| 根因（推断） | ① `app.conf` **`dbtype=4`** 连 OceanBase 空库，却检查/种子 **`ism.db`**；② 空 SQLite 启动时 `db.go` 用 `errors.Is(AdminUserError.Error, …)` **未创建 admin**（已修）；③ `ism_server` cwd 非 `ism_server_user` 导致 SQLite 路径落到**另一份空库** |

## 处置（仓库已补）

1. 查库：`grep ^dbtype= ism_server_user/conf/app.conf`；双口本机复测建议 **`dbtype=1`** + `httpport=8082`（本地 conf，勿提交覆盖团队 OB 默认时可仅本机改）。
2. 种子：`python3 scripts/xunzhi_jf_seed_admin.py --dbtype 1`  
   验证：`BASE_URL=http://127.0.0.1:8082 python3 scripts/xunzhi_jf_seed_admin.py --dbtype 1 --verify-login`（期望 **code 1000**）。
3. 文档：`docs/ISM-寻智-本机双开端口.md`「1003 → 查库路径 + seed」。
