## 对照总表（本轮只做 5–9）

| # | 现场现象 | 判断 | 本轮 |
|---|---|---|---|
| 5 | 控件绑点选设备，无论什么设备都只能显示两页点位 | 大屏分页优化把 `/getRealData` 默认改成第 1 页、每页 30 条；绑点弹窗 `deviceDataModel` 不传 `page`/`pageSize`/`fetchAll`，也不读返回的 `total`。表格 `pageSize=15` → 正好两页 | **绑点弹窗走 `fetchAll`（或按 `total` 翻页拉全量）**，大屏分页逻辑不动 |
| 6 | 撤销偶发不能撤回上一步；对齐后更明显 | 工具栏走 X6 `History`，对齐/旋转/翻转/组合在循环里逐节点改，**没有 `startBatch/stopBatch`**。一次「上对齐」变成 N 条历史，点一次撤销只退最后一个节点 | **几何操作包成一条历史**；撤销只走 X6 History，不和 Vuex 栈抢 |
| 7 | 两个旋转、两个镜像按钮无法正常使用 | ① 翻转写到 `this.selectedNode` 而不是循环里的 `NodeInfo`，且 `overwrite:true` 只带 `detail`，会冲掉节点 data。② 镜像靠 `transform=-1099/-1098`（`rotateY/X`），电力 SVG **不读这个字段**。③ 组合框是空壳，翻转只转青框不转子图元 | **对选中节点自身 `rotate`/`setData`；组则连子节点一起变；电力图元跟 X6 `angle`** |
| 8 | 已合并图形再与其它图形合并 → 提示「不能将节点添加到组中」 | `HeaderCreateGroup` / `CreateGroup`：选区里**任一节点已有 parent 就整批 return**。点已组合图元时选中的是子节点，二次合并被 ban | **选区先提升到顶层组；已有组与新图元做嵌套/并组，不再 ban** |
| 9 | 两组合上对齐只齐青框、不齐组内内容；全选再对齐更乱；对齐后无法撤回 | 对齐只 `setPosition` 选中节点的 bbox。组是空壳，子节点独立坐标；全选时组和子节点被当成平级分别对齐，子图元脱离组框。无 batch → 撤销只退一个 | **对齐以顶层组为原子；组移动带齐全部子节点；与 #6 共用 batch** |

现场原话收口：

> 简单来说这个合并功能只能进行拖拽移动，别的什么的不能进行。

组目前只是 X6 parent + 青色边框，**不是几何原子**：拖拽靠 X6 父子联动还能用；旋转/镜像/对齐/二次合并都按「独立 cell」处理，所以组内内容不是一个整体。

## 根因（第一性）

组态画布是 AntV X6。每个图元一个 cell；「合并」只是加一个 `view-ism-group-node` 父节点并把选中 cell `addChild`。父节点模板是空 `div`（青框），子图元仍是图上独立 cell。

因此：

1. **移动**：X6 移父节点会带子节点 → 现场觉得「合并只能拖」。
2. **对齐**：`HeaderAlignNodesTop` 对每个选中 cell 单独 `setPosition(..., baseY)`。选两个组 → 只齐两个青框的 `bbox.y`；组内开关符号相对组原点偏移不同 → 看起来「内容没齐」。全选（组+子）→ 子节点被拉到同一 `baseY`，脱离组框。
3. **旋转/镜像**：`revolve`/`reverse` 调 X6 `rotate`；`FlipVertical`/`FlipHorizontally` 改 `detail.style.transform` 魔法数，且写错对象（`selectedNode`）。电力组件模板没有 `rotateY/X`。组模板的 `transform` 只作用在空壳 div 上。
4. **二次合并**：`if (Parent) { message; return }` —— 禁止任何已入组节点再进新组。
5. **撤销**：X6 `History({ stackSize: 20 })`。循环里每次 `setPosition`/`rotate`/`setData` 各记一条。对齐 10 个控件 = 10 次撤销。再叠加 Vuex `undoStack`（`configData` deep watch）和 X6 栈并行，偶发「点了没退」。
6. **绑点两页**：数据仓库/大屏为防上万点一次打满，`GetRealData` 默认 `page=1, pageSize=30`。绑点弹窗仍按「一次拿全量、前端表格自己分页」写的，于是永远 30 条 / 两页。

```
现场绑点弹窗
  → POST /getRealData { uuid }   // 不带 page / fetchAll
  → 后端强制 page=1, pageSize=30
  → deviceDataModel.dataSource 只有 30 条
  → a-table pageSize=15
  → 分页器只出现 [1] [2]
```

大屏 `ViewRealTable` / `fetchAll` 路径不要改回全量，否则会回退「点位页卡死」。

## 本轮代码

### P0-1 绑点弹窗拉全量（#5）

文件：`ism-front-end-v2/src/components/deviceDataModel/deviceDataModel.vue`

- `getRealData` 增加 `fetchAll: true`（后端已有：`fetchAll && uuid` 走 `GetRealDataAllByNamePrefix`）。
- 若单次过大，改为读返回的 `total`/`hasMore`，按 `pageSize=200`（`RealDataMaxPageSize`）翻页拼齐，表格继续前端分页。
- **禁止**改 `GetRealData` 默认分页，大屏/数据仓库继续默认 30。

### P0-2 几何操作一条历史（#6、#9 撤销）

文件：`ISMHeader.vue`（对齐/旋转/翻转/组合）、必要时 `ISMCanvas.vue` 右键同样入口

- 所有「对选区循环改位置/角度/data」包在：

```javascript
graph.startBatch('align-or-transform')
try { /* 循环 */ } finally { graph.stopBatch('align-or-transform') }
```

- 工具栏撤销/重做只调 `ISMCavasContainer.undo()` / `redo()`。
- `canUndo()` 为 false 时按钮禁用，避免空点。

### P0-3 组是几何原子（#8、#9、#7 组场景）

文件：`ISMHeader.vue` 的 `HeaderCreateGroup` / `HeaderSetCommentsAlign` / `revolve` / `reverse` / `Flip*`；`ISMCanvas.vue` 的 `CreateGroup` 同步

- **选区规范化**：选中子节点 → 提升为顶层组；同一组的子节点去重，只保留一个组对象。
- **二次合并**：选区含已有组 + 未分组图元（或两个组）时，建新组或把新图元 `addChild` 到目标组，**删掉「不能将节点添加到组中」的整批 return**。
- **对齐**：只对齐规范化后的顶层 cell。组用 `setPosition` 平移，子节点跟 X6 父子联动，不再把子节点当平级对齐。
- **旋转/镜像**：组则对组节点做 X6 `rotate`，或按组中心对每个子节点做刚体变换（同一 Δx/Δy/角度），保证青框和内容一起动。

### P1 旋转镜像写对节点（#7）

- `FlipVertical` / `FlipHorizontally`：对循环里的 `NodeInfo.setData`，禁止写 `this.selectedNode`；禁止 `overwrite:true` 只带 `detail`（先 `getData()` 再改 `transform` 写回）。
- `revolve` / `reverse`：`angle` 空则当 0；`parseInt` 得到 `NaN` 时不转。
- 电力 SVG：跟 X6 节点 `angle`（或给模板加 `transform: rotate(angle)`），不要只靠 `-1099/-1098`。
- 未选中节点时按钮无操作、给提示。

## 明确不做

- 不把 `/getRealData` 默认改回全量（大屏会卡）。
- 不重写 X6 成真正的复合 path 合并（矢量布尔运算）。组仍是 parent+children，只补齐「当一个对象」的几何操作。
- 不改密码链、`ISMBase`、现场库数据、`native-bitunpack`。
- 0903 已修的导航/历史/脚本/电力绑态/图片/防抖，本轮不重开，除非现场确认未升包仍复现。

## 验收

- 绑点弹窗：点位数 > 30 的设备能翻过第 2 页，搜得到后面的测点。
- 连续对齐 / 旋转 / 镜像各一次，点一次撤销回到操作前；再点重做恢复。
- 选中电力开关或组合：旋转 90°、水平/垂直镜像，图元和组内内容一起变，不是只转青框。
- 已组合图元 + 新图元能再合并，不再弹「不能将节点添加到组中」。
- 两个组合上对齐：青框和组内符号一起齐顶；全选（含组内控件）再上对齐，不把子图元拽出组框。
