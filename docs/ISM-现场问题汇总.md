# 现场问题汇总

截图来自 `http://172.31.4.1:7180/#/hx-dcim`，页面已经能开。文档分两块。

## 配电室

1. **数据框要加指针，并且完整落在屏幕里。** 5A1 上，测点数据框固定贴在最右侧（红框里一串 `配电室5A1_U12`），不挪画面就显示不全，也离开了正在看的那台设备。改成：数据框带一根指针，指向当前目标框、目标设备；框的位置和大小自适应，整块都在屏幕内；指针和框都挨着目标，不躲到画面边上。
2. **个别 UPS 绑错了设备。** 5B2 上，悬停的柜子是 `5B2-T1-413-2 350 14主路`，弹出来的点却全是 `5B2_T1_413_1`（主路 1，不是 2）。名称和测点不是同一路。
3. **设备名称显示不下。** 5B2 上，小框里的「UPS维修旁路电源进线」被挤断，悬浮标题也在「旁」和「路」之间换行。希望名称按框的大小自适应，不要截成两截。
4. **线还没画好。** 2A2 上有两处红框：一处竖线在柜子中间断开，一处下面的横线没有接到竖线上。和这几天说的二层线没接上是同一类。

## 机房

1. **框框住了数字，没有框住闸。** 现在的 2A1 A 列头（TA）里，203 的方框套在数字上，闸在框下面。对照图是旧系统「中航信数据中心电力监控系统」：方框只套闸刀，柜号（101）在框上方，支路号（01A）在框下方。
2. **列尾没有图。** 2F 数据机房 2A1 的列尾 WA 打开后是空的，提示「暂无该列头大屏图」。左侧 WA 到 WJ 都是列尾。文档问的是没识别到，还是根本没画。
3. **文档没写字，图是网点位缺失。** 1B1 配电室网图里，COM6 的悬浮写着 `1B1_U1_X01_1` 未找到、点位不在点表里。这一条需要你确认是不是就指这个。

## 建议先做的顺序

- 数据框的指针、贴着目标、完整落在屏幕内，以及名称换行，都是前端显示，不改 CAD。
- 5B2 的 413-2 绑到 413-1，以及 1B1 点位不在点表，是测点绑定，要对照现场点表，不能猜着改号。
- 2A2 断线按已有一次图技能，只补没接上的线。
- 列头框改成套闸、数字留在框外；列尾 WA–WJ 先查是没有布局数据，还是房间号没对上。

## 技能要按改法回写

链路是：CAD 源文件 → 修图 → 一次图和 CAD 原图。改完一处，把错法和改法写进管这一步的技能，不要只留在对话里。源 DWG 字节不动。一次图和界面上的 CAD 原图都从修好的 DXF 出，同一套坐标和接法。

| 这次的问题 | 写进哪份 | 要写成的规则 |
|---|---|---|
| 数据框贴在最右侧、离开设备 | [ism-hx-power-oneline](.cursor/skills/ism-hx-power-oneline/SKILL.md) 的悬浮数据 | 数据框带指针，指向目标框和目标设备；整块落在屏幕内；挨着目标，不躲到画面边上 |
| 名称在框里被挤断 | 同一份技能的铭牌文字 | 名称按框自适应，不在词中间断开 |
| UPS 柜子和测点不是同一路 | 同一份技能的绑点 | 悬浮标题上的设备号必须和点名前缀一致，例如 413-2 不能弹出 413_1。对不上就标出来，不猜着改号 |
| 2A2 线没接上 | [ism-cad-repair](.cursor/skills/ism-cad-repair/SKILL.md) 和一次图技能里「线和铭牌没接上」「先修复 CAD，再出两张图」 | 先在修好的 DXF 里把端点收到该接的母线或铭牌边上，再同时生成一次图和 CAD 原图 |
| 列头框套住数字 | [ism-hangxin-knife-switch](.cursor/skills/ism-hangxin-knife-switch/SKILL.md) | 方框只套闸；柜号在框上，支路号在框下 |
| 列尾 WA–WJ 没有图 | 列头技能 | 列尾要有图，或写明 CAD 里没有、所以不画。不能只留「暂无该列头大屏图」 |

[cad-read-draw](.cursor/skills/cad-read-draw/SKILL.md) 只作入口。新规则写在上面的子技能里；入口若缺这条任务的指向，补一行，不把做法再抄一遍。

仓库 `.cursor/skills/` 和用户库里已经有的同名副本一起改，正文一致。用户库没有的技能不新建。1B1 网点位那条等确认后再写进绑点规则。

5. 列头三相：柜号在框上，方框只套闸，支路号在框下。单相仍然没有框。
6. 数据机房 2A1 的 WA–WJ：点表和 CAD 都没有列尾支路图，打开时写明所以不画。
