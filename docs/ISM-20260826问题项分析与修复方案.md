## 总判断

0825 完整包修了分类 Tag、切页保存、未绑定文案、备份 125 提示、Excel `GetCellValue` 读 0。今天文档里**仍复现**的主因不是「脚本写错」，而是三条未收口：

1. **脚本 -1**：`native-bitunpack` 源点 miss 就 skip，目标保持旧 `-1`；现场 `loglevel=3` 只落 Error，成功 Info 看不见。电能走 `anko-onchange` 所以能刷新。
2. **历史大部分查不到**：0825 打麒麟包时把未跟踪的 `tdengine_write.go` 挪走了，现场二进制仍是 `dealWithHistoryData.go` 里 **`TAGS(随机)`**。查询截图里「有功总电能 / 10 分钟」能查到，与「变化存储先建子表成功、后续大批次冲突」一致。
3. **Excel 整点**：导出映射把 type 3/4 都写成「变化存储」，导入也不认「整点存储 / 变化百分比」。

不关 `native-bitunpack`，不改密码链 / `ISMBase` / 数据仓库分类（今日文档未提）。
