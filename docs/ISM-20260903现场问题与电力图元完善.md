## 历史入库排查手册（现场 10 分钟）

现场「2208 点 / 600s 定时，界面查不到」先分清 **没库 / 没写入 / 查错点**，不要先改查询 API。

在 **`ism_server` 工作目录**（含 `logs/`、`conf/`）按序执行：

```bash
# 1) 入库失败
grep "write history data batch failed\|write TDengine history" logs/ism.log

# 2) 定时快照：wrote 只是入队，不等于已落盘
grep "timed history snapshot tick" logs/ism.log
# 看 wrote / notDue / intervalSec

# 3) 容器内库是否存在、表是否有数（容器名按现场 docker ps 替换）
docker exec <tdengine容器> taos -s "SHOW DATABASES;"
docker exec <tdengine容器> taos -s "SHOW ISMHistoryDb.STABLES;"
docker exec <tdengine容器> taos -s "SELECT COUNT(*) FROM ISMHistoryDb.HistoryDatas;"
docker exec <tdengine容器> taos -s "SELECT LAST_ROW(*) FROM ISMHistoryDb.HistoryDatas;"
```

4. 界面必须用 **具体测点 UUID + 入库当天** 查，禁止用单个 ECC 电能代表 2208 点。
5. 核对现场 `ism_server` 是否含 0826 `TAGS(1)`（没有则先换包，再谈查询 bug）。

判断：

- 库内 `COUNT` 接近 0：修写入（TAGS / 批次失败），不改查询页。
- 库内有数、界面无：再查时间窗、点 UUID、库名。
- 备份报「历史库未创建或连错实例」：先建库/改 `conf/historyData.conf` 指向的实例，不要死磕 taosdump 原文。

## 验收

- 菜单绑子页：不勾弹窗整页跳；勾弹窗只出子页，不套娃。
- 大屏按钮跳转子页，无常驻「页面加载中」。
- `SHOW DATABASES` 有库则备份成功；无库则接口说「库不存在」。
- 按本手册能在 10 分钟内判断 2208 点是未写入还是查错 UUID。
- 禁止脚本后不再 `SetDeviceData`；启用后不瞬间弹该脚本全部点。
- 电力开关：手车可选、断路器合闸闭合+变色、分闸还原。
- 两根直线改色互不影响；组合后一组绑点统一变色。
- 自定义图上传后运行态可见。
- 单点设 5s 防抖：抖 1s 不告警，持续 6s 告警。
