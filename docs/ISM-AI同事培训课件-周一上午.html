Part 1 · WorkBuddy · 主战场 25–30′

WorkBuddy 是什么

腾讯出品的全场景 AI Agent 办公工作台 · 口语「沃克巴」

  • 自然语言下任务——一句话也能开工
  • 自主规划、拆解步骤、调用工具执行
  • 交付文档 / 表格 / PPT 等可验收成果
  • 从「聊天问答」→「像同事一样把活干完」

周报 / 月报

报销 / 填表

票据信息 → 事由草稿 · 你点提交

查资料 · 对比

问题 → 摘要与待核实清单

做表 / PPT · 研发点到为止

大纲 → 骨架；报错 → 方案草稿

公式：输入 → AI 做什么 → 你验收什么

Part 1 · 怎么用

五步上手

打开→ 开对话→ 四件套指令→ 验收草稿→ 人点发送
1 目标

要交什么：表 / 邮件 / PPT

2 材料

看哪些文件、笔记；没有就说没有

3 约束

篇幅、语气、格式、不要改什么

4 验收标准

怎样算完成（页数、栏目、Owner）

Part 1 · 指令

差指令 vs 好指令

差「帮我弄一下周报。」
好「根据下面任务列表写周报：进展 / 风险 / 下周计划各三条以内；风险写影响；没有的完成项不要编。」

AI 爱「补全」——你要删掉编出来的完成项。

Part 1 · 专家与技能

Skill · 专家 · 专家团

Skill 技能

工具能力：让 AI 能做某件事
例：读表、出 PDF、连腾讯文档

专家

能力 + 经验：懂某个领域的 AI 角色
单点专业问题直接召唤

专家团

多专家协作：团长拆解、并行、交货
复杂任务再用

口诀：Skill 是手；专家是脑+手；专家团是一支小队。

入口：左侧「专家」/「专家·技能·连接器」

Part 1 · 口述演示

现场可走的脚本（选 1–2 个）

② 杂记 → 周报

Part 1 · 边界

适合什么 / 要谨慎什么

更适合
  • 多步办公：读材料 → 整理 → 交货
  • 结构清晰的周报、清单、对比表、幻灯骨架
  • 「帮我做完这件事」
需谨慎
  • 对客户承诺的最终决策
  • 未脱敏的客户全量数据
  • 期望「一次就对、不用验收」
  • 开通听部门安排，勿承诺全员已开
Part 2 · Grok Bot · 8–10′

Grok Bot：一人指挥一套助手

主助手

默认入口：问答、派活、汇总

专项助手 / 项目助理

盯某一类活或某一个项目，少重复交代背景

电脑端

长任务、多文件、持续跟进

手机端

路上补一句、催进度、看结果

口语「五克巴蒂」= Grok Bot · 常见：「WorkBuddy 交货，Grok Bot 跟线」

Part 2 · 搭配

WorkBuddy 与 Grok Bot

WorkBuddy

办公工作台 / Agent 交货
文档 · 表格 · PPT · 专家 / Skill

Grok Bot

助手体系 · 跟项目 / 跟催
电脑 + 手机一体指挥

不是二选一。账号开通按部门安排。

Part 3 · 微信指挥 · 5–6′

目标形态：手机 ↔ 电脑

微信发指令→ 机器人桥接→ 电脑侧执行→ 结果回传验收

人在手机上指挥，重活在电脑上干，两边不断档。

Part 3 · 诚实口径

目标形态 ≠ 已全员上线

  • 能演示到哪一步，以现场账号 / 绑定为准
  • 部分同学需单独开通，不是人人一点即有
  • 未开通：先练下指令习惯（WorkBuddy 同样适用）

短指令示例：「整理三条行动项，Owner 先空着。」

Part 4 · EMS · 8–10′

从「个人提速」到「工作被管起来」

AI 帮你起草和催办；人确认之后，进 EMS——工作才真正被管起来。
  • WorkBuddy / Grok Bot / 微信：把活干快
  • EMS：合同、台账索引、软著资质、审批等逐渐有一本账
  • 今天讲方向与已能看见的能力，不声称已全量交付
Part 4 · EMS

能管什么（可讲范围）

相对方 / 合同

登记 · 附件索引 · 状态与到期

财务台账索引

流水 / 凭证索引 · 非核算、非开票

软著 / 资质

进度 · 材料索引 · 证书台账

文档索引

标题 · 路径 · 关联对象 · 不搬文件

审批中心（方向）

待办与确认留痕

勿讲成已交付

项目仅占位；采购 / 交付写能力未就绪

公式：AI 起草 → 人确认 → 进 EMS

Part 4 · EMS

智能化怎么接进来

WorkBuddy

日常交流互动 · 随手交货

Grok 挂 EMS

助手打开界面 · 查/填/催

EMS 内嵌智能体

系统里直接问与操作

接法：EMS API → MCP / 工具门禁 → 助手（不直写库）

目标形态；勿称已全员开通。下一刀优先：项目 / 采购 / 交付（未交付）

Part 4 · 部署

公司要弄：外网怎么进？

外网给同事用
  • 固定公网 IP（或域名 → IP）
  • HTTPS（证书）
  • 优先：阿里云 ECS + 弹性公网 IP
内网 / 本机 demo
  • 办公室机器本地起即可
  • 自建外网：运营商固定 IP + NAT / 端口映射 + 7×24 在线，更难运维

内网先跑通；开外网优先云主机。权限与备份另定，本场不替 IT 拍板。
