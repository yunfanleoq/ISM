# ISM 大屏告警区：历史查询分离

## 结论

首页右侧栏布局为：

1. **上方**：功率趋势 (24h)（平滑图；**20260724 起已去掉用电量趋势**，见 [ISM-RC08bate-20260724大屏修改.md](./ISM-RC08bate-20260724大屏修改.md)）
2. **右下角**：活跃告警浮层（`ScadaAlarmPanel`，约 584×320）
3. **历史查询**：告警面板标题栏「历史查询」按钮 → 全屏抽屉（复用报表页 `Reporting/AlarmHistory`），不在侧栏内嵌表单

侧栏不再放置 `AlarmHistoryComponents`（Ant Design 完整查询表单不适配窄高 foreignObject）。

## 交互

```
右侧栏
├── 功率趋势
├── 用电量趋势
└── 活跃告警（浮层）
      ├── 历史查询 → 全屏抽屉（筛选/翻页/导出）
      ├── 条数 / 启动延迟 / 清除
      └── 实时列表（可滚动）
```

抽屉内可再点「打开完整报表页」新开管理端告警报表。

## 主要文件

| 文件 | 作用 |
|------|------|
| `ism-front-end-v2/src/pages/ISMDisPlay/ScadaAlarmPanel.vue` | 右下角活跃告警 +「历史查询」按钮 |
| `ism-front-end-v2/src/pages/ISMDisPlay/ScadaAlarmHistoryDrawer.vue` | 全屏抽屉，内嵌告警历史报表 |
| `build_ncc_dashboard.py` → `append_overview_side_panels` | 生成双趋势 + 告警占位；不生成侧栏历史组件 |

坐标对齐（画布 1920×1080）：告警区约 `(1312, 736, 584×320)`。

## 已部署项目落地

| 场景 | 做法 |
|------|------|
| 发前端即可 | 「历史查询」按钮与抽屉；告警浮层高度回右下角 |
| 右侧仍是挤在一起的「告警历史查询」表单 | 重跑 `build_ncc_dashboard.py`（或等价克隆脚本）写回首页；或组态编辑器删除 `AlarmHistoryComponents`，按脚本恢复两个平滑趋势图 |
| 组态工具箱仍可拖入告警历史组件 | `make_alarm_history` 保留，仅首页生成不再调用 |

## 验收

1. 总览页右侧上方为两个趋势图，右下角为活跃告警列表（可滚、可配条数）。
2. 点「历史查询」→ 全屏抽屉，查询/翻页/导出可用；关闭后回盯屏，轮询不停。
3. 钻探子页时告警浮层仍隐藏；KPI 覆盖正常。
