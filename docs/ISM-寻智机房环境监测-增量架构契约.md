## 1. 模块边界与调用链

### 1.1 模块地图（两月范围 vs 二期）

| 模块 | 两月 | 调用允许 | 禁止 |
|------|------|----------|------|
| **监测（采集+实时）** | ✅ 主交付 | 协议 → RealData → WS → 组态 | 展示层直连串口/驱动；跨项目写点 |
| **告警** | ✅ 加固 | RealData/触发器 → 告警表 → 通知/大屏 | 告警模块改点表；绕过确认清历史 |
| **可视化（平面组态大屏）** | ✅ 航信/1A 模式 | 读 RealData/告警/树；钻取到测点 | 产品级 2.5D 引擎当两月必达；Bootstrap 重做 UI |
| **权限** | ✅ 复用四级角色 | 控制类 API 鉴权+二次确认+日志 | 匿名写控制；明文存口令 |
| **南北向** | ✅ 南向为主；北向预留 | 南向：采集器/微模块北向接入本平台；北向：现有推送能力声明 | 两月内新建完整上级对接产品 |
| **资产** | ⚠️ 最小（树+虚拟机柜列） | 园区…机柜层级挂设备 | U 位全生命周期/合同管理当两月验收 |
| **容量 NSPC** | ❌ 二期 | — | 写入两月验收用例 |

### 1.2 调用链（验收向）

```
现场设备/采集器/微模块北向
  → [南向] Modbus|SNMP|OPC UA|BACnet|MQTT|S7|RESTFul/HTTP
  → DeviceRealData (+ 队列)
  → ├─ WebSocket → 组态大屏 / 监测页
  → ├─ 告警引擎 → DevicesAlarmList → 屏显/语音桩/通知配置
  → └─ 历史任务 → TDengine → 历史曲线/报表
权限横切所有写 API；远程控制：权限 → 二次确认 → 下发 → 审计日志
```

## 2. 采集链路

### 2.1 协议复用表

| 方案要求 | ISM 已有 | 两月处理 |
|----------|----------|----------|
| Modbus RTU/TCP | ✅ | **复用**；温湿度/漏水/配电/UPS/空调主路径 |
| SNMP | ✅ | **复用**；UPS/网络设备等 |
| BACnet | ✅ | **复用**；暖通/空调若现场为 BACnet |
| OPC / OPC UA | ✅ OPC UA | **复用** OPC UA；经典 OPC 未单列则标「须增量或网关」 |
| MQTT | ✅ | **复用**；物联网网关 |
| S7 | ✅ | **复用**；若有西门子侧 |
| http/https | ✅ RESTFul 推送 + OpenAPI | **复用**；微模块北向 HTTP/JSON 优先 |
| 私有协议 | 视厂商 | **有协议则通，无则契约+Mock**（W3 北向结论签字） |
| 动环采集器串口汇聚 | 南向经采集器再 TCP/Modbus | 点表按采集器寄存器/对象建模，不虚构直连能力 |

### 2.2 点表 schema（字段级最小集）

每测点必须具备（落在协议数据模型 + `DeviceRealData`）：

| 字段 | 语义 | 必填 |
|------|------|------|
| `point_id` / ModelDataUuid | 测点唯一 ID | ✅ |
| `device_id` / DeviceUuid | 所属设备实例 | ✅ |
| `name` | 显示名 | ✅ |
| `signal_type` | AI/DI/AO/DO/告警量 | ✅ |
| `unit` | 工程单位（℃、%RH、V、A、kW…） | AI 必填 |
| `protocol` | modbus/snmp/… | ✅ |
| `address` | 寄存器/OID/NodeId/对象实例等 | ✅ |
| `data_type` | 布尔/整型/浮点/字符串 | ✅ |
| `byte_order` | 若 Modbus 多寄存器 | 条件 |
| `scale` / `ConversionExpression` | 换算 | 推荐 |
| `gather_interval_ms` | 采集周期（支撑 ≤10s） | ✅ |
| `alarm_enable` / level / hi/lo | 告警开关与阈值 | 告警点 ✅ |
| `record_enable` / record_type | 历史策略 | 曲线点 ✅ |
| `offline_default` | 离线默认 | 推荐 |
| `tags` | room/rack/system 等检索标签 | 推荐 |

**设备类型最小清单（两月须有模型+样例点表）**：温湿度、漏水、配电（电量仪/列头柜关键量）、UPS、精密空调/CDU 关键量、氢气；电池单体 = 大量测点接入路径可开，**健康度/放电报告产品 = 二期**。

### 2.3 ≤10s SLA 度量

| 度量点 | 定义 | 探针 |
|--------|------|------|
| M1 周期完成 | 单项目「管辖设备」一轮采集 wall time | 采集日志 `cycle_ms` / 系统分析接口 |
| M2 入库可见 | 点值写入 `DeviceRealData` 时间戳 − 采集完成 | DB/API 抽样 |
| M3 界面刷新 | WS/拉数到组态控件更新 | 前端打点或人工秒表（目标界面 ＜5s，方案值） |
| M4 告警到达 | 越限产生 → 告警列表/大屏可见 | ≤15s（方案 Web）；ECC≤6s 作设计目标，硬件未齐时记「未测」 |

**失败重试**：单点/单设备超时按模型超时重试；连续失败 → 设备离线状态 + 离线默认值 + 可选离线告警；禁止无限打满串口。  
**风暴抑制**：同一测点告警抖动 → 屏蔽/恢复延时/触发器防抖（复用 AlarmShield + 触发器）；通知通道限频（同级同设备合并）；大屏弹窗可聚合。

**勾选**
- [ ] W2 起有周期日志可证明两类动力可采
- [ ] 点表含 gather_interval，汇总可论证 ≤10s（点数规模写入已知问题表若超限）

## 4. 告警

### 4.1 级别枚举（与方案对齐）

| 级别 | 码（建议） | 处理优先级 |
|------|------------|------------|
| 紧急 | 1 | 最高；声光/语音桩 + 屏显 |
| 重要 | 2 | 屏显 + 配置通知 |
| 一般 | 3 | 屏显/列表 |
| 提示 | 4 | 列表为主 |

### 4.2 生命周期

```
产生(active) → 确认(acked) → 清除/关闭(cleared|closed)
                 ↘ 派单(二期工单) / 挂起(可选，若已有则复用)
```

- **产生**：越限/状态变位/离线/触发器。  
- **确认**：操作者+时间入库；未确认可督办（列表标红）。  
- **清除**：采集恢复或人工关闭；保留历史。  
- **与工单**：两月 **接口边界 = 告警 ID 可被外部引用**；完整「告警—派单—归档」工单产品 = **二期**，验收不测工单闭环。

### 4.3 通知通道

| 通道 | 两月 | 说明 |
|------|------|------|
| 屏幕显示 | ✅ | 大屏告警面板 + 实时告警页（已有） |
| 语音 | ⚠️ 桩 | 无扬声器硬件则接口/配置桩 + 日志「应播报文」 |
| 声光 | ⚠️ 桩 | 无硬件则 DO/接口桩；有则接开关量 |
| 邮件/钉钉/短信等 | 复用已有 AlarmNotice | 按现场开通，非本契约必达硬件 |

- [ ] 确认闭环可演示
