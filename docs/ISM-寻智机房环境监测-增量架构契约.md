## 一句话目标

在 **ISM 现网底座**上，以约两月窗口启动、**同窗交付**公安局新建机房 DCIM 向全量建设内容：动环采集主链 + 告警闭环（含工单衔接）+ 资产 U 位生命周期 + NSPC + 能耗 PUE/碳 + 可视化（平面组态 → 2.5D）+ 安防消防接入 + 麒麟补丁 / 双机软件就绪；实现形态为 **相对独立子模块**，库表 **部分共享**。栈：**Go + Beego + Vue2 组态**，非 SpringBoot。

## §1 同窗范围与非目标

### 1.1 同窗范围内（按技术方案建设内容）

| 域 | 同窗交付内容 |
|----|----------------|
| **监测** | 温湿度/配电/UPS/蓄电池单体/空调·CDU/漏水/氢气/微模块北向；≤10s 周期；实时 WS + 历史 |
| **告警** | 四级分级、确认/清除、通知（屏/语音桩/声光桩）、策略；**与工单闭环衔接** |
| **资产 U 位** | 园区…机柜树；U 位精细管理；入库/上架/变更/下架/报废等生命周期；机房 2/3 纳管能力（≥4000 机柜） |
| **NSPC 容量** | 网络/空间/供电/制冷建模、水位、预占、推荐上架（同窗切片可先最小闭环再加厚） |
| **工单知识库** | 告警—派单—处理—确认—归档；知识沉淀 |
| **能耗 PUE/碳** | 分层级用电/功率；PUE 计算（含手工补录）；碳排放分析 |
| **可视化** | 平面组态大屏（航信/1A 模式）→ **2.5D 导航目标**；图表加厚至 ≥50/≥20；多机房远程监测 |
| **安防消防** | 视频授权点位、门禁/入侵报警事件、消防报警接入与联动状态（接口/硬件依赖时用降级条件） |
| **电池专项** | 1920 单体测点接入路径 + 健康度/放电类能力（按方案；依赖采集器就绪） |
| **双机热备** | 方案要求同窗；硬件未齐时：**软件就绪 + 演练计划** = 可验收切片 |
| **权限** | 分模块、分权限、分角色（≥四级 RBAC）；远程控制二次确认 |
| **南北向** | 南向采集为主；北向对接更高等级环境监测：接口形态 + 样例/联调窗口 |

### 1.2 非目标（仅限下列 · 勿把业务能力写入非目标）

| 非目标 | 处理 |
|--------|------|
| SpringBoot / 微服务重写监测主系统 | **禁止**；对外口径 = ISM 增量 |
| UI 按方案 Bootstrap 换肤重做 | **禁止**；沿用 Ant Design Vue + 现有组态 |
| 编造合同金额 / 商务验收日 | **本文不写金额**；已中标可开工 |
| 宣称等保已测评 / 密评已通过 | **禁止**；仅写设计项；测评状态=**未标明** |
| 直接覆盖现网麒麟生产目录 | **禁止**；只发独立补丁包 |
| 误并他线交付包 | 见上文「范围边界」 |

> **不要**把 U 位 / NSPC / 工单 / 2.5D / PUE / 双机 / 安防消防 / 电池专项标成非目标或「二期」。

## §2 子模块地图（相对独立）与调用链

### 2.1 子模块清单

| 子模块 | 代号 | 职责 |
|--------|------|------|
| 动环采集主链 | `envmon-collect` | 协议 → RealData → 队列/历史；点表与设备模型 |
| 告警 | `envmon-alarm` | 分级、生命周期、通知、风暴抑制 |
| 组态/大屏/2.5D | `envmon-viz` | DisplayModel、平面大屏、2.5D 导航、图表模板 |
| 资产与 U 位 | `dcim-asset` | 资产台账、U 位图、上下架/报废流程（相对独立） |
| NSPC 容量 | `dcim-capacity` | 空间/供电/制冷/网络水位与预占 |
| 工单与知识库 | `dcim-workorder` | 工单闭环、知识条目 |
| 能耗/PUE/碳 | `dcim-energy` | 分项计量、PUE、碳排放 |
| 权限 | `envmon-iam` | 复用并扩展 ISM User/Roles；RBAC、数据范围 |
| 南向适配 | `envmon-south` | 协议驱动、微模块北向适配、Mock |
| 北向适配 | `envmon-north` | 向上级环境监测推送/OpenAPI 预留 |

### 2.2 允许 / 禁止调用方向

```
                    ┌──────────── envmon-iam（横切鉴权）────────────┐
                    ▼                                               ▼
现场/采集器/微模块 → envmon-south → envmon-collect → DeviceRealData
                                              │
                    ┌─────────────────────────┼─────────────────────────┐
                    ▼                         ▼                         ▼
              envmon-alarm              envmon-viz                 历史/TDengine
                    │                         ▲
                    │ 告警可触发工单            │ 只读测点/树/告警
                    ▼                         │
              dcim-workorder                  │
                    │                         │
dcim-asset ←──读/写空间与机柜主数据（唯一真相）─┤
     │                                         │
     └──读──→ dcim-capacity（读树+功率测点）    │
                                              │
dcim-energy ←──读 RealData 功率/电量；可写手工补录
```

| 规则 | 说明 |
|------|------|
| **允许** | 资产/容量 **读** 空间树与功率类测点；告警 **触发** 工单；可视化 **只读** RealData/告警/树；能耗 **读** 测点 + 写手工补录表 |
| **禁止** | 资产/容量/工单/能耗 **反向改采集驱动或点表**；展示层直连串口；绕过 `dcim-asset` 双写机柜/U 位造成双真相；跨项目未经授权写点 |
| **与动环主链关系** | `envmon-collect` 为监测真相源；DCIM 子模块挂接空间与业务，**不**替代采集 |

### 2.3 验收向主调用链

```
现场设备/采集器/微模块北向
  → [南向] Modbus|SNMP|OPC UA|BACnet|MQTT|S7|HTTP
  → DeviceRealData (+ 队列)
  → ├─ WebSocket → 组态/2.5D / 监测页
  → ├─ 告警引擎 → DevicesAlarmList → 通知 →（可选）工单
  → └─ 历史任务 → TDengine → 曲线/报表/能耗
权限横切所有写 API；远程控制：鉴权 → 二次确认 → 下发 → 审计
```

**勾选**
- [ ] 无 SpringBoot 新服务进程进入发版包
- [ ] 前端依赖仍为 Ant Design Vue（非 Bootstrap 换肤重做）
- [ ] 大屏数据仅来自 ISM RealData/告警 API/WS，无旁路库直连
- [ ] 机柜/U 位变更只经 `dcim-asset` API

## §3 共享表 vs 子模块私有表

### 3.1 共享表原则

1. **空间与监测主数据优先共享**：项目树 / MonitorList / 设备与测点 / RealData / 告警 / 用户角色 / 组态 / 时序历史。  
2. **业务过程进私有表**：资产单据、U 位占用、容量预占、工单、知识库、PUE 手工录入等，前缀建议 `xunzhi_` 或 `dcim_`。  
3. **外键语义**：私有表通过 `project_id` / `room_id` / `rack_id` / `device_uuid` / `alarm_id` 引用共享实体，**不复制**整棵监测树。  
4. **写边界**：共享监测表仅 `envmon-collect` / `envmon-alarm`（及既有 ISM 配置路径）可写；DCIM 模块写私有表 + 经资产模块更新机柜主数据字段。

### 3.2 共享（ISM 已有或扩展）

| 表/载体 | 用途 | 主要写者 | 读者 |
|---------|------|----------|------|
| 项目树 / `MonitorList` | 园区…设备树 | 配置/导入/`dcim-asset`（机柜节点） | 全模块 |
| 协议 `*DevicesDataModel` | 点表模型 | 配置/1A 包复制 | collect |
| `DeviceRealData` + 内存 Map | 实时值 | collect | WS、alarm、viz、energy、capacity |
| `DevicesAlarmList` + 队列 | 告警 | alarm | viz、workorder、通知 |
| TDengine 点历史 | 曲线/报表 | 历史任务 | viz、energy、报表 |
| `DisplayModels` / Layer JSON | 组态/大屏 | viz 编辑器 | 运行时 |
| `User` / `Roles`（及扩展） | 账号角色 | iam | 全 API |
| `conf/app.conf` + `data/auth/` | 配置/密钥 | 运维 | 进程 |

### 3.3 子模块私有（新建 · 最小字段）

| 表（建议名） | 模块 | 最小字段 |
|--------------|------|----------|
| `dcim_asset` | asset | asset_id, asset_tag, type, model, status, rack_id, u_start, u_height, owner_org, project_id |
| `dcim_rack_u` | asset | rack_id, u_index, occupied, asset_id, max_weight_kg, rated_power_kw |
| `dcim_asset_ticket` | asset | ticket_id, asset_id, action(in/up/change/down/scrap), state, applicant, approver, ts |
| `dcim_capacity_snapshot` | capacity | room_id/rack_id, dim(N/S/P/C), total, used, reserved, ts |
| `dcim_capacity_reservation` | capacity | reservation_id, rack_id, dim, amount, holder, expire_at, state |
| `dcim_workorder` | workorder | wo_id, alarm_id?, title, priority, state, assignee, sla_due, created_at |
| `dcim_wo_event` | workorder | wo_id, event(type), actor, note, ts |
| `dcim_kb_article` | workorder | kb_id, title, tags, body, related_alarm_code, updated_at |
| `dcim_pue_manual_entry` | energy | entry_id, scope(room/campus), metric, value, period, editor, ts |
| `dcim_carbon_factor` | energy | factor_id, energy_type, factor, effective_from |

空间实体（Campus/Building/Room/MicroModule/Rack）优先落在共享树扩展字段；不足时用 `dcim_space_attr` 扩展，避免平行 CMDB 双树。

## §4 子模块接口契约

**路径前缀建议**：`/api/xunzhi/jf/...`（与 ISM 既有 `/api/...` 并存；鉴权同一套 JWT/会话）。若合入 ISM 惯例控制器，须在 PR 注明等价路由。

| 模块 | 输入（示例） | 输出 | 同步/异步 | 错误语义 |
|------|--------------|------|-----------|----------|
| collect | 点表导入、采集启停 | RealData、cycle 指标 | 采集循环异步；查询同步 | `400` 点表非法；`503` 驱动离线 |
| alarm | 策略 CRUD、ack/close | 告警列表/详情 | 同步写；通知异步 | `409` 重复确认；`403` 无权限 |
| viz | 画面 CRUD、绑定 point_uuid | 画面 JSON、模板枚举 | 同步 | `404` 画面不存在 |
| asset | 资产 CRUD、上架校验 | 台账、U 位图、占用率 | 同步；审批可异步 | `422` U 位冲突/承重超限 |
| capacity | 水位查询、预占申请 | NSPC 视图、推荐位 | 同步 | `409` 预占冲突 |
| workorder | 从 alarm_id 建单、流转 | 工单详情、SLA | 同步；升级异步 | `404` 告警不存在；`403` 非处理人 |
| energy | 范围+周期、手工补录 | PUE/电量/碳 | 同步 | `422` 补录越权范围 |
| iam | 登录、角色授权、数据范围 | token、权限集 | 同步 | `401`/`403` |
| south/north | 适配配置、Mock 开关 | 联通性、样例载荷 | 同步探测；推送异步 | `502` 对端失败 |

**通用**：写操作须带操作者；控制类须二次确认 token；审计字段（who/when/what/result）必填。

## §5 采集 / 点表 / ≤10s

### 5.1 协议复用表

| 方案要求 | ISM 已有 | 同窗处理 |
|----------|----------|----------|
| Modbus RTU/TCP | ✅ | **复用**；温湿度/漏水/配电/UPS/空调主路径 |
| SNMP | ✅ | **复用** |
| BACnet | ✅ | **复用** |
| OPC / OPC UA | ✅ OPC UA | **复用 OPC UA**；Classic 见 §0.1（范围外补充） |
| MQTT / S7 / HTTP | ✅ | **复用**；微模块北向 HTTP/JSON 优先 |
| 私有协议 | 视厂商 | 有协议则通；无则契约+Mock（§0.3） |

### 5.2 点表 schema（最小集）

| 字段 | 语义 | 必填 |
|------|------|------|
| `point_id` / ModelDataUuid | 测点唯一 ID | ✅ |
| `device_id` / DeviceUuid | 所属设备 | ✅ |
| `name` | 显示名 | ✅ |
| `signal_type` | AI/DI/AO/DO/告警量 | ✅ |
| `unit` | 工程单位 | AI 必填 |
| `protocol` / `address` / `data_type` | 寻址 | ✅ |
| `byte_order` / `scale` | 换算 | 条件/推荐 |
| `gather_interval_ms` | 支撑 ≤10s | ✅ |
| `alarm_*` / `record_*` | 告警与历史 | 条件 |
| `tags` | room/rack/system | 推荐 |

**设备类型（须有模型+样例点表）**：温湿度、漏水、配电、UPS、精密空调/CDU、氢气、电池单体（大量测点路径）、微模块北向对象。

### 5.3 ≤10s SLA 度量

| 度量点 | 定义 | 探针 |
|--------|------|------|
| M1 周期完成 | 管辖设备一轮 wall time | `cycle_ms` 日志 |
| M2 入库可见 | 写入 RealData − 采集完成 | DB/API 抽样 |
| M3 界面刷新 | WS/拉数到控件 | 目标 ＜5s |
| M4 告警到达 | 越限 → 列表/大屏可见 | ≤15s（Web）；ECC≤6s 硬件未齐记「未测」 |

**风暴抑制**：屏蔽/恢复延时/触发器防抖；通知限频；大屏弹窗聚合。  
**失败重试**：超时重试 → 离线状态 + 离线默认值；禁止打满串口。

## §6 告警生命周期 + 工单衔接（同窗闭环）

### 6.1 级别

| 级别 | 码 | 处理优先级 |
|------|-----|------------|
| 紧急 | 1 | 最高；声光/语音桩 + 屏显 |
| 重要 | 2 | 屏显 + 配置通知 |
| 一般 | 3 | 屏显/列表 |
| 提示 | 4 | 列表为主 |

### 6.2 生命周期（含工单）

```
产生(active) → 确认(acked) → 派单(dispatched) → 处理中(in_progress)
             → 挂起(suspended, 可选) → 清除/关闭(cleared|closed) → 归档
                                      ↘ 知识沉淀(kb)
```

- **产生**：越限/变位/离线/触发器。  
- **确认**：操作者+时间入库。  
- **派单/处理**：`dcim-workorder` 引用 `alarm_id`；状态回写告警扩展字段或关联表。  
- **关闭**：采集恢复或人工关闭；保留历史；工单归档可回写关闭原因。  
- **同窗须演示**：至少一条「告警 → 工单 → 归档」闭环（可用 Mock 告警）。

### 6.3 通知通道

| 通道 | 同窗 | 说明 |
|------|------|------|
| 屏幕显示 | ✅ | 大屏 + 实时告警页 |
| 语音 / 声光 | 桩或实装 | 无硬件 → 接口/配置桩 + 应播日志（降级条件） |
| 邮件/钉钉/短信等 | 复用 AlarmNotice | 按现场开通 |

## §9 模块划分 · 共享表原则 · 权限/角色模型 · 与动环主链边界

> 本节应项目经理/用户要求单独成节，与 §2–§3、§4 互参。

### 9.1 模块划分（分模块）

- **监测域**：`envmon-collect` / `envmon-south` / `envmon-alarm` / `envmon-viz` / `envmon-north`  
- **DCIM 域（相对独立）**：`dcim-asset` / `dcim-capacity` / `dcim-workorder` / `dcim-energy`  
- **横切**：`envmon-iam`  
- 代码落地建议：Go 包或 Beego 模块目录按上表隔离；前端路由按模块挂菜单；**同一进程发版**，非独立 Spring 服务。

### 9.2 共享表原则（摘要）

见 §3：监测与账号共享；业务单据私有前缀；禁止 DCIM 写协议驱动表。

### 9.3 RBAC 模型（分权限 · 分角色）

#### 角色枚举（≥四级 · 可扩展）

| 角色码 | 名称 | 典型职责 |
|--------|------|----------|
| `R1_viewer` | 只读监测员 | 看实时/告警/大屏；不可控制、不可改配置 |
| `R2_operator` | 运维操作员 | 告警确认、工单处理、有限远程控制（须二次确认） |
| `R3_engineer` | 配置工程师 | 点表/组态/资产上架变更、策略配置 |
| `R4_admin` | 系统管理员 | 用户角色、数据范围、系统参数、审计查询 |
| （扩展）`R2b_duty` | 值班长 | 工单派发升级、跨班组确认 |
| （扩展）`R3b_asset` | 资产管理员 | 资产全生命周期审批，无采集驱动权 |

#### 权限资源（按子模块）

| 资源前缀 | 示例动作 |
|----------|----------|
| `collect:*` | 查看周期、启停采集（高敏） |
| `alarm:read/ack/close/config` | 告警读写与策略 |
| `viz:read/edit` | 大屏查看/组态编辑 |
| `asset:read/write/approve` | 台账与流程 |
| `capacity:read/reserve` | 水位与预占 |
| `workorder:read/create/transit` | 工单 |
| `energy:read/manual_entry` | 能耗与补录 |
| `iam:user/role/scope` | 账号与数据范围 |
| `control:device` | 远程控制（灯光/空调等） |

#### 数据范围

- 绑定维度：`campus_id` / `building_id` / `room_id` / `project_id`（可多选）。  
- 列表与写操作必须过滤数据范围；跨范围须 `R4_admin` 或显式授权。  
- 机房 2/3 远程监测：给市局监测中心角色授予对应 `room/project` 只读或运维范围。

#### 与远程控制二次确认

```
control:device 权限检查 → 弹出二次确认（口令或确认码）→ 写审计 → 下发 → 记录结果
无 control:device 或数据范围不命中 → 403；跳过二次确认 → 拒绝并记安全事件
```

### 9.4 与动环主链边界

| 边界 | 规定 |
|------|------|
| 真相源 | 测点实时值 = `envmon-collect` → `DeviceRealData` |
| 空间主数据 | 机柜/U 位占用以 `dcim-asset` 为准；采集侧设备挂载位置变更须走资产 API |
| 容量 | 只读功率测点 + 资产 U 位；不改 gather |
| 工单 | 消费告警 ID；不改告警历史真实性 |
| 可视化 | 只读绑定；禁止组态保存时改寄存器地址（地址属点表域） |
