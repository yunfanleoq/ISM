## 本轮代码

### A. native skip settle

- `loadSourceValue` 增加设备名/点名别名（`设备->列头_点名` ↔ `设备->列头` + `点名`）
- miss 时复用该源点上次成功拆位的原值，禁止永久 skip 导致目标锁在 -1
- `SettleAll` / `SettleAllQuiet` 优先走带告警的 setter（与手动 Exec 一致）
- 空字符串不当作有效源值

### B. 整点存储 type=4

- 快照加载 `is_record=1 AND record_type IN (1,4)`
- type=4 间隔由 `record_data_timely`（1=5min … 5=60min）对齐截断
- 采集路径对 type=4 与 type=1 一样交给快照独占，避免双写

### C. ViewMenu 保存

- 保存 pageId：`selectPageUuid` → 树节点 → 当前页信息
- 序列化前给菜单 cell 补 `animate.selected` / `animateElement`
- `toJSON` 失败时给出明确错误，不再静默失败

### D. 数据仓库设备名

- 优先 API `DeviceName` / `deviceName`，没有再按下划线拆 `name`

### E. 告警清除

- `AlarmUpdate` 找不到未消除行返回失败（不再 ID=0 假成功）
- 大屏活跃告警行可点清除
- 手动单条清除离线告警时不再立刻 `ResyncOfflineDeviceAlarms`

### F. 新页当背景（诊断）

现场黄条与「未配置设备测点模板页」一致。先在现场执行 `scripts/bootstrap_device_signal_template_mysql.sh`。保存时用解析后的旧 pageId，避免新建页过程把当前画布写进错误页。

## 明确不做

- 不重写 taosdump、type=1 快照主路径、Excel upsert、密码链、ISMBase、`actions.js`、100+ `animateType`
- 不关 `native-bitunpack`

## 验收

1. 组态页：换背景可保存；再拖导航菜单并绑定画面后仍可保存，切页回来内容还在
2. 整点存储：5 个 type=4 点一小时内各有对应档（按 5/10/15/30/60 分钟间隔）
3. 按位脚本：源点缓存暂时为空时目标不再长期 -1；源点有值后 native 与 anko 都能拆位并推报警
4. 数据仓库：设备名称列可筛选，优先显示后端设备名
5. 实时告警：点一条清除后该条从实时列表消失；找不到行时提示失败；离线告警手动清后不立刻弹回同一条
