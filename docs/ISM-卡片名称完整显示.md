# ISM 运行态卡片名称完整显示

## 目标

仅优化最新运行态中的设备卡片和点位卡片名称，不改首页组织树、实时绑定、翻页和模板解析链路。

## 实现

- 设备名称优先完整显示，支持最多两行；名称变长时自动降低字号。
- 极长名称保留首尾关键信息，中间使用 `…` 省略；卡片 `title` 始终保留原始全名。
- 点位名称在当前设备名前缀后存在明确分隔符时，移除重复设备名前缀；相似但无分隔符的名称不裁剪。
- 展示名称与原始名称分离，原始名称继续用于卡片键、绑点、实时数据查询和悬停全文。
- 字符截取使用 Unicode 字符数组，避免拆坏中文、英文混排和 Emoji。

## 运行态与模板关系

- `/AppRun/:uid` 首页使用组织树卡片。
- 进入组织后，由机房/设备列表模板结合 `navContext` 动态生成设备卡片。
- 进入设备后，由通用或物模型设备模板结合 `navContext` 动态生成点位卡片。
- 编辑器“PC 页面”展示物理模板；左侧“运行态页面”入口负责带上下文预览最终卡片效果。因此，不能因静态模板中没有具体设备卡片而删除运行模板。

## 验证结果

- 两个目标 Vue 文件 ESLint 通过，IDE 诊断无新增问题。
- 浏览器验证最新 `/AppRun/b8b4c094-faa9-a22a-1d0d-037539b27a6c`：
  - 首页为组织树；
  - 组织下显示 49 个设备卡片；
  - 设备内显示 19 个点位卡片；
  - 名称样式为两行上限，短名称保持原字号；
  - 点位实时值区域、单位和 LIVE 标识正常；
  - 极长中文、英文、数字和 Emoji 混排名称可正确保留首尾。
