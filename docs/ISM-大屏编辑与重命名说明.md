# ISM 大屏编辑与重命名说明（给现场/李总）

> 对应 V3.01.RC08bate 反馈：「大屏编辑如何使用，更新名称后结构是否自动更新」

## 1. 两套机制，不要混用

| 机制 | 做什么 | 典型入口 |
|------|--------|----------|
| **脚本生成 / 克隆** | 按项目设备树生成/克隆首页、设备列表、测点页 | `build_ncc_dashboard.py`、`scripts/clone_hx_3page_dashboard_to_chaifa.py` |
| **组态编辑器（模板模式）** | 改真实页面模板的 cells 布局与绑定 | 应用管理 → 设计 →「编辑对应模板」 |

运行态预览（选中组织/设备节点时看到的虚拟页）只是把模板按当前 `navContext` **深拷贝解析展示**，**不会写回数据库**。要改布局必须点「编辑对应模板（全局生效）」再保存。

更细的技术说明见 [ISM-运行态页面编辑映射.md](./ISM-运行态页面编辑映射.md)。

## 2. 改名后，结构会不会自动更新？

| 你改了什么 | 大屏会怎样 |
|------------|------------|
| 设备管理树里改区域/设备名称 | 运行态左侧导航树、按树解析的文案会更新 |
| 组态里改页面 `PageName` | **只改页面标题**；不会重建组织层级，也不会重生成 KPI/告警区 cells |
| 首页写死的品牌字、静态标签 | **不会**随设备改名变化，需手改模板或重跑生成脚本 |
| 三页模板绑定（home / deviceList / datapointList） | 靠 UUID / `template_kind`，与显示名无关 |

**结论**：改名 ≠ 重建大屏结构。结构由「模板 + 运行时 monitortree」驱动；要整体换布局请编辑模板或重新生成。

## 3. 推荐操作步骤

1. **日常微调布局**：运行态 → 进入编辑器 → 点「编辑对应模板」→ 拖拽/删改组件 → 保存。  
2. **核对能源 KPI（总功率/今日用电）**：系统参数 → 能源总览 → 按现场测点名调关键字 → 看覆盖率。  
3. **在线设备 / 活跃告警**：运行态由 `ScadaAlarmPanel` 实时覆盖；活跃告警在右下角，可改「条数」并滚动；「历史查询」打开全屏抽屉（见 [ISM-大屏告警区历史分离.md](./ISM-大屏告警区历史分离.md)）。  
4. **需要整页换版（如侧栏误嵌告警历史表单、要恢复双趋势）**：用生成脚本重写首页图层，或在模板里删除 `AlarmHistoryComponents`、拖回两个平滑趋势图。

## 4. 常见误解

- 「我改了页面名称，为什么左边树还是旧结构？」——树来自设备管理，不来自页面名。  
- 「预览里改了怎么保存不上？」——预览禁止写回；请切到「编辑对应模板」。  
- 「在线设备一直是固定数？」——旧包可能是生成时快照；新版本由系统数据实时刷新。
