# ISM 寻智 · bjga 公安局大屏五级钻取演示剧本

> 入口：`http://127.0.0.1:7081/#/xunzhi/jf/viz/bjga`（循智双口；航信为 7080/8081）  
> 空间巡检 Tab：`#/building` 或 `#/building/drill5`（直达园区起点）  
> 账号：`admin` / `123456`（Leader/User/Operator 亦可见「空间巡检」宏菜单）

## 五级路径（固定口径）

| 级 | 名称 | 面包屑 | 主操作 | 期望画面 |
|---|------|--------|--------|----------|
| 1 | 园区 | 信息化园区（高亮） | 点击中央 **数据中心主体楼** 卡片 | 园区底板 + 右侧「五级演示路径」步骤条 |
| 2 | 楼 | 园区 › 数据中心主体楼 | 点击楼体 SVG **楼层热区**（如 3F），或侧栏 **五级演示·进入 3层2#数据机房** | 楼体立面 / 楼层平面；面包屑第 2 级高亮 |
| 3 | 房 | … › 3层2#数据机房 | 在楼层平面点击机房色块，或使用侧栏快捷进入 | 机房平面/机柜阵列；右侧机房 KPI |
| 4 | 柜 | … › xx 机柜 | 点击机柜色块，或侧栏 **五级演示·进入机柜** | 42U 机柜排布 / 3D 机柜视图 |
| 5 | 设备 | … › 品牌 型号 | 点击机柜内 **U 位条**（如 `SIM-3M2-无号-01`） | 设备详情 + 机柜内高亮 U 位 + 右侧测点 |

**演示锚点数据（种子）**

- 机房：`3层2#数据机房`（`3F`）
- 机柜：`3M2-无号`（有在架设备）
- 设备示例：`SIM-3M2-无号-01`（服务器）

## 逐步操作

### 0. 启动（本机）

```bash
# 后端 8082
cd ism_server_user && ./ism_server

# 前端 7081（含 /api → 8082 代理）
cd ism-front-end-v2
NODE_OPTIONS="--max-old-space-size=8192 --openssl-legacy-provider" npx vue-cli-service serve --port 7081
```

登录后打开：`/#/xunzhi/jf/viz/bjga` → 顶栏 **空间巡检**。

### 1 园区

1. 进入空间巡检后默认在 **园区**（若落在楼体，点面包屑 **园区** 返回）。
2. 确认顶栏面包屑仅 **园区** 为高亮。
3. 点击中央 **数据中心主体楼**。

**期望**：进入楼体立面；面包屑为 `园区 › 数据中心主体楼`。

### 2 楼

1. 在楼体 SVG 上点击 **3F** 热区（或侧栏「五级演示 · 进入 3层2#数据机房」跳过楼层平面直达机房——仍算完成 2→3 的演示动作）。
2. 若进入楼层平面，面包屑仍为第二级 **楼** 高亮（楼层名附在楼后）。

**期望**：内容区切换为楼层/楼体视图；可点面包屑 **园区** 回到 L1。

### 3 房

1. 在 3F 平面点击 **3层2#数据机房** 色块（若用侧栏快捷按钮则直接进入）。
2. 确认面包屑第三级 **3层2#数据机房** 高亮。

**期望**：机房机柜阵列；侧栏出现「五级演示 · 进入机柜」。

### 4 柜

1. 点击阵列中 **3M2-无号** 机柜（或侧栏演示按钮）。
2. 面包屑第四级机柜名高亮。

**期望**：42U 列表或 3D 机柜；U 位条可点。

### 5 设备

1. 在机柜视图中点击一条 **有设备的 U 位**（推荐 `SIM-3M2-无号-01`）。
2. 面包屑第五级显示设备型号；主区为设备详情 + 高亮 U 位。

**期望**：右侧「设备测点（演示）」卡片；`Esc` 返回机柜。

## 面包屑回退

| 点击面包屑 | 回到 |
|-----------|------|
| 园区 | 园区总览 |
| 数据中心主体楼 | 楼体（保留楼层上下文时清空房/柜/设备） |
| 机房名 | 机房平面 |
| 机柜 | 机柜 42U |
| 设备 | 设备详情 |

## 失败回退

| 现象 | 处理 |
|------|------|
| 白屏 / 动环数据未加载 | 确认已登录；`curl -H "Authorization: …" http://127.0.0.1:8082/bjga/bootstrap` 返回 `code:1000` |
| 无「空间巡检」Tab | 用 `admin` 或角色含 macro 的账号；或直链 `#/building/drill5` |
| 3D 卡顿 | 侧栏切换 **2.5D** 或机柜页切换 **清单** 模式 |
| 机柜无 U 位 | 换演示机柜 `3M2-无号` 或点侧栏演示按钮 |
| 面包屑与画面不一致 | `F5` 刷新后从 `#/building/drill5` 重走 |
