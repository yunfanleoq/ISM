## 判定

网表「红色母线」只列出长于 15 个图单位的红横线。31 间里没有一条红母线刚好盖住某一编号组、组外刀不超过 2 把。网表因此列不出「这几把共一条小横母线」。编号串本身不当成并联，避免把单刀改成横刀。

画面上同一行、柜号带到 `-1`、间距均匀的一组，若刀上口附近有红色小横线（一段或几段接起来，不把更长的主母线算进去）盖住整组，并且只有一把刀有向上的红竖线，记为符合。竖线在 `-1` 上是标准挂法。II 段原先有 11 组竖线在另一端（`-2` 或 `-5`），仍然只有一根，小横母线也在。这 11 组都有 `-1`，竖线 x 已挪到 `-1` 上口。没有缺 `-1`、因而保留原挂点的组。

要改挂线的只有两种：每把刀各有一根竖线挂到主母线，或刀被横置。横置指刀数据里 `orient` 为横、宽大于高，或同柜号堆成纵列。这两种都是 0。原先竖线已在 `-1` 的挂线未改。
