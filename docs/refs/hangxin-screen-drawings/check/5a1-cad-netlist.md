# 5A1 配电室一次图 · CAD 网表（唯一标准）

- 标准源：`docs/refs/gongan-dashboard/group-files/配电系统图.dwg`（与 `docs/refs/hangxin-screen-drawings/配电系统图.dwg` 字节一致，`cmp` 无差异）。
- 解析方式：`dwg2dxf`（libredwg，Homebrew）转到 `/tmp`，自写 DXF 组码解析器（ezdxf recover 读该 DXF 报二进制段错误）读取 ENTITIES/BLOCKS，INSERT 按块展开变换；按 5A1 区域 `x∈[-2605,-2315]、y∈[6180,6425]`（标题「5A1配电室」MTEXT 在 `(-2492.6, 6442.3)`）框选 LINE/LWPOLYLINE/ARC/TEXT/MTEXT，渲染局部放大图逐段读线。转换产物只在 `/tmp`，不入库。
- 辅助：`word-figures/图1-CAD-5A1配电室.png`（整体走向一致）、`图2-手绘一次图.png`（排版参照，逻辑以 CAD 为准）。
- 本机有 `/Applications/MiniCAD.app`，未用它截图：实体坐标比截图读线更精确，且可复核。
- 坐标单位为 DWG 模型空间单位；「依据」列的 x 指该柜标注文字 x（柜名 TEXT，y≈6405.8 / 6342.5 / 6314 / 6252 / 6195）。
- 下文「上端/下端」按 CAD 画法：顶排柜刀上端朝顶母线；UPS 输出柜、Y 柜同理上端朝电源侧。

## 7. 并联 / 共引下汇总

画面（`20261027cad5a1e`）全部竖刀，外框同尺寸 **60×98**。横置刀纵排（旧 pargroup）仅对 5A1 作废。

| 类型 | 回路 | 显示画法 |
