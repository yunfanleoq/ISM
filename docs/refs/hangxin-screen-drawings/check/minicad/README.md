## 截图清单

## 整体布局（自上而下四层）

```
 T1 ─401─┤═════ I 段母线 (红) ═════┤445├═════ II 段母线 (红) ═════┤─402─ T2
          410 411组 412 413 414 415 416 445  426 425 424 423 422 421组 420
                    │   ║   ║   ║   ║          ║   ║   ║   ║   │
                    │  U11 U12 U13 U14        U24 U23 U22 U21  │      ← 500kVA UPS ×8
                    │   │   │   │   │          │   │   │   │   │
                   XBP X01-1 X01-2 X02-1 X02-2  X02-2 X02-1 X01-2 X01-1 XBP
                    └──┴─────┴─────┴─────┘    └─────┴─────┴─────┴──┘
                    U1 输出母线 (红)              U2 输出母线 (红)
                  X11        X12                X11      X12
                   │          └→Y02→Y14/Y15/Y16  │        └→Y02→Y14/Y15/Y16
                   └→Y01→Y11/Y12/Y13              └→Y01→Y11/Y12/Y13
```

- 左右两半基本镜像：左边 T1 / I 段 / U1，右边 T2 / II 段 / U2；II 段从左到右编号是倒序（426→421）。
- **母线分段**：顶部红线分两段。I 段从 401 的上翻竖线到 445；II 段从 445 母联的上翻竖线到 402 的上翻竖线。两段之间留有空隙，只靠 445 连接。

### 1. 进线（401 / 402）

- 5A1-T1（2000kVA）：上圈 Δ、下圈 Y（中性点接地）。低压出线**向下 → 右拐 → 竖线向上**，到母线高度后用一段**短红线**接到 **401 上口**。这段短红线和 I 段母线之间有约 3 个单位的缺口，**两者不相连**。
- **401（4000A，总输出柜）**：上口接变压器，经「上插头 → 断路器 → 下插头 → 3×CT」后**从下口引出 → 右拐 → 竖线向上**，接到 I 段母线左端。也就是说，进线柜是「上进下出、再翻上母线」。
- 402 / T2 完全镜像。

### 2. I 段母线上的回路（从左到右）

| 位置 | 编号 | 额定 | 用途 | 上端 | 下端 |
|---|---|---|---|---|---|
| 1 | T1-410 | 630A | 电容补偿柜 | 母线（熔断器式负荷开关） | 小母线 → 两组电容 + 避雷器 + 「···」 |
| 2 | T1-411-1~5 | 160/250/250/630/630A | 411-1 是 5A1 市电测试箱，411-2~5 备用 | **共用一根小母线**，小母线只在 411-1 处用一根竖线挂到 I 段 | 各自出线（无去向） |
| 3 | T1-412 | 4000A | 5A1-U1 大旁路 | 母线 | **蓝线**直下到 **U1-XBP** |
| 4~7 | T1-413-1/-2 … 416-1/-2 | 1250A | 500-n# 主路 / 旁路 | 每对两台抽屉**共用一根短横线**，只在 **-1（主路）** 处挂上母线 | -1 **紫线** → U1n 整流器输入；-2 **绿线** → U1n 静态旁路 + 维修旁路 |
| 8 | 445 | 3200A | 母联 | **I 段** | 下口 → **红线**右拐 → 竖线向上接 **II 段左端** |

II 段：423~426（1600A）对应 U21~U24，-1 主路 / -2 旁路规则同上；422（4000A）大旁路接 U2-XBP；421-1~5 共用小母线，在 421-1（5A3 市电测试箱 160A）处挂上 II 段，其余备用；420 电容补偿。

### 3. 「并联 / 备用组」的画法

- **一个柜、多个抽屉**的画法：在主母线下方约 2.6 个单位处画一根白色短横线（小母线），各抽屉从小母线往下垂，**只有一根竖线**把小母线挂到主母线上。411、421（5 抽屉）、413~416、423~426（2 抽屉）、Y11~Y16（4 抽屉）都是这个画法。
- 挂点永远在「-1」那台抽屉上：I 段在组的左端；II 段因为镜像，在组的右端（421 挂在 421-1，即最右）。

### 4. UPS 区（U1 / U2）

- 每台 500kVA UPS 都画了内部结构：输入开关 → 整流器 → 直流母线（接电池开关和电池符号）→ 逆变器 → 输出开关；旁路输入 → 静态开关（双晶闸管）；另有一路维修旁路开关，三路在输出侧汇合，然后向下接到 X0n-m。
- U11→X01-1（UPS1 进线）、U12→X01-2、U13→X02-1、U14→X02-2，均为 1000A。**X01-1 与 X01-2 的下口用横线并在一起**，在 X01-1 处接到 U1 输出母线；X02-1/-2 同理；**U1-XBP（4000A）** 也直接接到这条母线。所以结构是：UPS1+2 并联、UPS3+4 并联，加上大旁路，三路都汇到同一条 U1 输出母线。U2 镜像。
- U1 输出母线画成红色、略倾斜的一条线（从 x≈-2596.6 到 -2456.3，两端 y 差约 0.8），不是严格水平。

### 5. 出线：X11/X12 → Y01/Y02 → Y11~Y16

- U1 输出母线上挂两路：**U1-X11**、**U1-X12**（2000A，UPS 电源出线）。
  - X11 → 长竖线 → **U1-Y01**（2000A，数据机房 5A1 UPS 电源进线）→ 下层红母线 → **Y11/Y12/Y13**，每组 4 路 400A：5A1-A~K 列头，Y12-4、Y13-4 备用。
  - X12 → **U1-Y02**（数据机房 5A2）→ 中层红母线 → **Y14/Y15/Y16**：5A2-A~K 列尾，Y15-4、Y16-4 备用。
- U2：X11 → U2-Y01（数据机房 5A4）→ Y11~Y13：5A4 K~A 列尾，Y12-4、Y13-4 备用；X12 → U2-Y02（数据机房 5A3）→ Y14~Y16：5A3 K~A 列头，Y15-4 备用，Y16-4 为电力监测电源。
- **Y11~Y16 是并联，不是串联**：同一条母线上的 3 个柜子各自挂一根竖线，每个柜子内 4 路出线又并在柜子的小母线上。从 X11 到 Y01 是「UPS 输出柜的出线开关 → 电缆 → 列头配电柜的进线开关」，一根电缆两头各有一个断路器（这是唯一的串联关系）。
- 每路出线最下面是 3 行文字框（编号 / 电流 / 用途），框下没有再往下画线，「OUT」就是这个框。

## 刀闸符号尺寸

- 所有断路器回路都是同一套块，按固定顺序竖向叠放：**上插头 `DYDQAA03`（向上的双 V）→ 断路器 `DYDQ0201`（斜刀 + 上端 ×）→ 下插头 `DYDQAA04`（向下的双 V）→ 3 个 CT `A$C03DD39B5`（圆圈加短斜线）→ 柜号框**。
- 5A1 框内共有 **97 个断路器块**，缩放比例**全部是 0.213、旋转角 0°**，斜刀长度都是 1.52 个单位。4000A 进线、3200A 母联、1250/1600A 的 UPS 支路、400A 的 Y 出线，**画的都是同样大小的刀**，图形尺寸和额定电流无关。上下插头、CT 的缩放比例也全部统一（0.213 / 0.002）。
- 不属于这套块的符号：410/420 电容补偿柜（熔断器式负荷开关、隔离开关、电容、避雷器、接地，块 `$element…`、`M_M4/M_M23/M_M44IVD/M_M17/M_M24`）、变压器（双圆），以及 **UPS 内部开关**。UPS 内部开关是散线画的，没有 ×，斜线长 1.38 或 0.82，比标准刀小。

## 线在哪里相连、哪里只是交叉

- **5A1 区域内没有实心连接点**（没有 donut、SOLID 填充点）。连接全部靠线端落在另一根线上（T 形接头）。唯一的小圆圈（半径约 0.09，空心）只出现在 410/420 电容小母线的分支点和变压器中性点。
- 用几何方法检查了框内 983 段导线（只算模型空间的散线，不含块内部），共有 8 处真正的「穿过」：
  - **U2 区 4 处：紫色主路输入线与绿色旁路横线交叉（不相连）**，位置在 U21~U24 上方 y≈6379。U1 区布线错开了，没有这种交叉。
  - 2 处：U2-X11 和 U2-X12 的竖线在 y≈6304.8 被一根很短的红横线穿过，竖线在这里断开后又接上。U1 侧没有这个画法。**用途待确认**（像是电缆分界标记，也可能是图层残留）。
  - 2 处是线端稍微伸出母线（421 的挂线、U1-X12 的挂线伸出约 0.05~0.5 个单位），按 T 形连接理解。
