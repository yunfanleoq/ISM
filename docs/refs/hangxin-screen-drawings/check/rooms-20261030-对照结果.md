# 配电室新旧图对照结果

说明：新图 = 6 张新整理的 DXF（5A1、5A2、5A3、5B1、5B2、5B3）；旧表 = 旧总图生成的 5A1.md…（5B4、5A4 本次无新图，未比对）。

## 方法与解析情况

- 用 ezdxf 的 recover 模式读取 DXF（LibreDWG 转出，读取无致命错误，仅有少量自动修复）。中文文字解码正常（TEXT/MTEXT 的 SimSun 格式码已清理）。
- 刀编号：取 TEXT/MTEXT 中形如“房号-T1-4xx[-n]”“房号-U1/U2-…”“445（母联）”“A?-2xxx”的文字，去掉房号前缀后与旧表比。用途文字按“编号正下方、横向最近”关联，关联不上的留空。
- 交叉验证：每把刀由 3 个刀块（DYDQAA09）组成，各图刀块数÷3 与提取到的编号数完全一致：5A1=97、5A2=97、5A3=13、5B1=111、5B2=113、5B3=16，说明没有漏解析。
- **电流**：新图几乎没有电流文字（只有 5B2 的两处 630A；其他全无 xxxA）。旧表的电流来自别处，所以**新图无法核对电流**，电流一栏除 5B2 的 A5-2131 外都无法比较，不是“一致”，而是“新图没有”。
- 新图的刀块没有 ATTRIB 属性，块名只有 DYDQAA03/04/05/09、DYDQ0201 等通用符号，不带编号，编号全部来自文字。
- 新图的 TEXT 上没有“刀数”之类的汇总，请以下面统计为准。
