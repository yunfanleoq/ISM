## 现场原话

报表模板点进去是白的，原来能插点位的表格出不来。原先没测，写进 24 号文档。

## 原因

编辑页是 `diyReportContent.vue`（路由 `#/Reporting/ReportTempleteContent/:uuid`）。

1. 表格只在 `activated()` 里初始化，`mounted()` 是空的。多页签关掉时不走 keep-alive，`activated` 不跑，中间一直白。
2. xlsx 按 `/static/reportTemplete/{uuid}.xlsx` 去拉，不走 `/api`。开发态 7080 没有这条代理；现场若 nginx 把 `/static` 指到前端打包目录，同样 404。LuckyExcel 拉空就 `return`，不建表、也不报错。
3. 容器写了 `z-index: -1`，表格会被压到卡片底色后面。

## 本轮落地

| 项 | 文件 |
|---|---|
| 带登录头下发 xlsx | `GetReportTempleteFile`：`reportTempleteCtl.go` + `router.go`；文件不存在时建空表 |
| 编辑页初始化 | `diyReportContent.vue`：`mounted` / `activated` 都会建表；xlsx 走 `/api/GetReportTempleteFile`；去掉 `-1`；拉失败打开空白表并提示 |
| 文案 | `language.js` 增加 `diyReportTemplete.LoadFailed` |

## 验收

1. 报表 → 报表模板 → 点「模板内容」，中间应出现 LuckySheet 表格，不是白块。
2. 新加、还没保存过内容的模板，应打开一张空表。
3. 右键仍可插入测点变量；保存后再进，内容还在。
