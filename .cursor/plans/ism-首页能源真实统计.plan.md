# 首页能源真实统计

## 实施范围

1. 按项目配置一台进线总表及四个明确测点，不进行名称模糊匹配或自动设备求和。
2. 自动开启配置测点的 60～300 秒定时历史记录，当前开发环境历史数据落主库。
3. 后端统一返回三类实时功率、今日用电量、24 小时功率平均曲线和分时用电量曲线。
4. 首页四个组件按 `energyOverviewRole` 使用共享统计数据；无真实数据时显示空态并禁用示例曲线。
5. 保持现有组态绑定解析、ISMRender 实时分发和普通图表行为不变。

详细口径、配置和数据流见 [docs/ISM-首页能源真实统计.md](../../docs/ISM-首页能源真实统计.md)。
