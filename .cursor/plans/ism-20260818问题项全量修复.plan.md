## 问题 2a 现场日志（未修好）

```
HisDbBackUp docker taosdump failed: Cannot get the attribution of the terminal: Inappropriate ioctl for device
ERROR: /tmp/ISM_TDengine_Backup_2026-08-18_09-46-53/ is not exist!
```

代码里容器路径为 `/tmp/<distName>`，但 **`docker exec` 前未 `mkdir -p`**，taosdump 要求输出目录已存在 → 直接失败。  
`ioctl` 为无 TTY 环境下的噪音，可用 `docker exec -i`（勿加 `-t`）减轻，不是主因。

## 问题 3（native vs anko）

- `native-bitunpack`：脚本能被 bitunpack 编译则走原生，日志 `native-bitunpack: ...`
- `anko-onchange`：编译不过则走 Anko 解释执行，现场称这条能解析且报警
- 若现场脚本被 native 吃掉但告警链路不完整，会出现「有解析日志、无报警」

需对照：该脚本日志是 native 还是 anko；native 路径是否写实时值并触发告警队列。
