# 航信闸刀画法

本技能在用户 Agent Store，全环境可用。产品绘画规则原文见 [references/绘图方法.txt](references/绘图方法.txt)（与 ISM 仓库 `docs/refs/hangxin-screen-drawings/绘图方法.txt` 同步）。ISM 里新大屏实现在 `ism-front-end-v2/public/hx-dcim/js/hx-draw.js` 的 `knifeInner`。改完刀形要改 `public/hx-dcim/index.html` 里 `hx-draw.js` 的缓存参数。取数逻辑不要跟着刀形改。

一把刀只有一种颜色。合闸整把红，分闸整把绿。`is-closed` 只画合闸组，`is-open` 只画分闸组，不要两层叠在同一把刀上。

公理：刀开着，刀后面的线必须是绿的；刀合着，刀后面的线必须是红的。不能刀片是绿的、出线却是红的。竖刀后面是下方，横刀后面是右侧。出线侧铭牌同色。进线侧和母线保持红。母联两端都不涂绿。

CAD 原图里刀口朝上还是朝下，按 DXF 插入的旋转和缩放核对，不能只看左右。整图 Y 取反只做一次；块局部坐标不要再反一次，也不要漏反。左右不要跟着对调。见 `ism-hx-power-oneline`「连接线突出要分左右量，块先缩放再旋转」。共享刀符号的半圆弧和斜刀坐标不为此改。

一次图换刀时不描块里的笔画（含 DYDQAA09 重复短线），换成共享符号，长轴 140px。铰接和刀口上下跟 DXF/SVG 一致：先缩放再旋转，不要先旋转再缩放。铰接放在块展开后的轴线端点上，不要用 `source_bus_x` 吸到最近的竖母线；同一列四把刀的这个端点必须仍然共线。2A2-T1-411-1～5 刀口朝上，刀轴左端贴在竖母线上。2A2-U1-Y11 的轴线左端是 89.1265，不是母线 87.0918。见 `ism-hx-power-oneline`「横刀铰接被吸到不同母线」。

对齐不能靠吸母线。换符号后块外缺的线按每把刀在 SVG/DXF 里的实际端点和方向分开补：竖刀上端有的接短竖线、有的接到短横，下端接馈线；横刀只补还没贴到符号端点的那一截。不要 100 把补同一侧。见 `ism-hx-power-oneline`「换符号后缺线要按每把刀的端点补」。

横刀的轴线、左边红进线、右边绿出线必须同一高度。绿弧浮在线上方是分闸刀片离开轴线张开，不是刀轴掉下去，不要为了这个弧去移轴。2A2 的 U1-Y11-1：DXF、SVG、JSON 的模型 Y 都是 208.368，画面 Y 约 4162.7，红线与绿线只差 0.26 像素。见 `ism-hx-power-oneline`「横刀轴线和进出线同一高度」。

## 两种状态

| 状态 | 颜色 | 画什么 |
|---|---|---|
| 合闸 / 联通 / 值 1 | 全红 `#ff0000` | 半圆弧留在上方。竖线从母线一直连通到底。不画斜刀片。 |
| 分闸 / 没联通 / 值 0 | 全绿 `#00ff00` | 半圆弧 + 一条斜直线。竖线在铰接处断开。 |

白点、`OUT`、白色下箭头两种状态都留。支路刀（`decor`）才带 OUT 和下箭头，进线主开关不带。

## 分闸锚点（不要改）

半圆弧：`M30 52 A13.2 13.2 0 0 1 30 78`。圆心约 (27.71, 65)。

斜直线：`x1="18" y1="44" x2="39.51" y2="70.92"`。

- 上端 (18, 44) 是上方铰接小圆的圆心。
- 下端贴在半圆弧下部 1/3 的分界上（弧长参数约 t=2/3），不贴上沿，不贴弧的正中。
- 分闸竖线只画到铰接点 y=44，再从下触点 y=86 接到 y=114。

合闸用同一条半圆弧和同一组触点圆点，竖线是 `x1="18" y1="0" x2="18" y2="114"`。合闸组里不要放那条斜直线。

## 列头柜怎么摆

三相：测点名末尾有 A/B/C 的，一个框里三把刀。方框只套这三把闸。柜号在框上方，支路号（如 203A、203B、203C）在框下方。不要把柜号的字号框画成 60×98，否则方框会套在数字上，闸露在框下面。对照旧系统：柜号在框上，支路号在框下。文字和方框都要用自己的宽高，不能落回刀的默认框。

单相：没有 A/B/C 后缀的单独一把、不要框。307 就是这种。机房按实际支路画，编号可以比设计图多。

列尾：数据机房 2A1 的 WA–WJ 是列尾。点表只有机房模块 2A1 的 A–J 列头，没有列尾点。CAD 一次图里只有「2A1-A列尾」这类馈线标注，没有列尾柜支路大屏。所以不画。打开时写明「点表和 CAD 都没有这列列尾支路图，所以不画」，不要只留空白或「暂无该列头大屏图」。别的房间若点表和 CAD 里有列尾布局，再按上面的框法画。

刀闸本身：合闸全红、分闸全绿。出线侧跟闸状态走（竖刀下方 / 横刀右侧；合红=有电，分绿=无电），出线侧铭牌同色。母线、进线上游线不跟单刀变色。母联（两端都接电源母线）开合都不把两侧涂绿。

按 CAD 改配电一次图时读 `ism-hx-power-oneline`（用户 Store 与项目 `.cursor/skills/` 各有一份）。
进线、电容补偿柜、顶母线分段和 UPS 主路/旁路连通以那份为准。
本技能只定刀片红绿和刀形，不要在一次图布局里改半圆弧或斜刀坐标。
补偿柜：产品规则（绘图方法）写界面不展示；一次图仍按该室 CAD——有则画、无则不硬补。5A1 的柜号不要套到其他配电室。
CAD 总入口：`cad-read-draw`。
