# 按 CAD 改配电一次图

改 `hx-dcim` 配电室一次图时先读本页。刀闸红合绿分、分合刀形、`knifePickId` 去重以 `ism-hangxin-knife-switch` 为准，本页不重复那些规则，也不要在布局里改刀形。

组态大屏 cells 走 `ism-scada-dashboard`。本页只处理按 CAD 改的电力单线图。

## 什么时候读

用户要改配电一次图、对照 CAD、改 5A1 以外的配电室、或问进线、母联、电容补偿、UPS 主路/旁路是否接通时。

## 标准图

唯一标准是这两份，内容相同，都不要改：

| 文件 | 作用 |
|---|---|
| `docs/refs/gongan-dashboard/group-files/配电系统图.dwg` | 标准 |
| `docs/refs/hangxin-screen-drawings/配电系统图.dwg` | 副本 |

两份 MD5 都是 `c58f0fb1dfacc088b8f6f470ffd2b6d5`。动手前再算一次。对不上就停，不要用另一份 DWG 当标准。

macOS 预览打不开 DWG。看图用 MiniCAD（CAD迷你看图 5.1，Bundle `com.tianji.MacMiniCad`，支持 dwg/dxf/dwf）。看不清通常是缩放到空白处，先缩到全图再点进该室，不是文件被改。

用户截的局部图比离线猜拓扑可靠。和离线读图冲突时，以用户确认过的局部图为准。5A1 已归档在 `docs/refs/hangxin-screen-drawings/check/`：

- `5a1-cad-user*.png`
- `5a1-cad-u11-join.png`
- `5a1-cad-t1-401*.png`、`5a1-cad-t2-402.png`
- `minicad/README.md`（看图方法和截图清单）

`minicad/*-dwgrender.png` 是同一份 DWG 用 LibreDWG 渲染的高清图，用来读字。连通关系以用户局部图和 DWG 几何为准。`minicad/README.md` 里「401 上进下出、再翻上母线」是更早的读图，已被后来的 401/402 局部图否定，不要再按那段绕线。

## 房间外框不画，只复刻框内

CAD 里贴着配电室外围的红矩形只表示这间房的范围，不是母线，不要画。读图以这只矩形为准：上下两条红线左右端对齐、至少一侧有竖边、边上没有刀。标题可以带「新建」（`1A2配电室新建` 仍是 1A2）。只把矩形里面的一次图按 CAD 相对位置落坐标，包括顶母线、竖刀、中间的紫/绿/蓝线、下层出线母线和出线刀、补偿柜、变压器。框下面另一间的刀不要因为离标题近就被拽上来。

外框的判据是四边贴着本室范围、上面没有刀；两边都伸出刀云、上面也没有刀的长红线同样丢掉。母线端点只比最后一个接线点多伸出约 24px。左右两块在框内母线是断开的，不要用外框或加长红线把它们连起来。两段母线中间有空档就保持断开。竖刀仍是 60×98，不要改刀形。网表里没有进线、补偿柜或变压器符号，不要硬补。5A1 已核对的内部接线不重画；若只是多了外框，只删外框。

## 从这份 DWG 读某一间

macOS 用 Homebrew 的 LibreDWG（`dwg2dxf`）。不要把整份 DXF 提交进仓库，转换只放 `/tmp/hx-power-system.dxf`。ezdxf 读这份 DXF 会崩，用仓库里的组码解析。

动手前脚本会再算 MD5，不是 `c58f0fb1dfacc088b8f6f470ffd2b6d5` 就停。

```bash
# 在仓库根目录
python3 ism-front-end-v2/public/hx-dcim/scripts/read_cad_power_room.py list
python3 ism-front-end-v2/public/hx-dcim/scripts/read_cad_power_room.py room 3A1
python3 ism-front-end-v2/public/hx-dcim/scripts/read_cad_power_room.py emit
```

| 产物 | 内容 |
|---|---|
| `docs/refs/hangxin-screen-drawings/check/cad-rooms/index.md` | 1～5 层和 ECC 的房间清单 |
| `check/cad-rooms/<室号>.md` | 该室网表：柜号、电流、标注、红母线、有没有场景测点 |
| `public/hx-dcim/data/hx-power-rooms/<室号>.json` | 画面布局。5A1 不写进这里 |
| `data/hx-power-rooms/index.json` | 画面要加载的房间 |

读法要点：大字号（约 10）的「3A1配电室」才是这间的标题。字高约 1.1 的同名文字是别的图上的馈线标注，不要当成第二间。刀的锚点是块 `DYDQAA03`。柜号用该室自己的文字（`T1-401`、`T7-410-1`、`U1-Y11-1` 都可以）。补偿柜经常没有这个刀块，用柜号文字补一把竖刀。进线刀和补偿柜的母线必须落到刀上口；CAD 里这截有时只剩一两个单位，脚本会补上。不要把 5A1 的 401/411/U11 套到别的室。

投到画面：CAD 的 Y 向上，画面 Y 向下，要翻转。刀块插入点对到竖刀顶边中点；竖刀 60×98，JSON 里 `x` 是左缘、`y` 是顶边，顶边中点是 `x+30`。同一岛内，画面 x = 参照刀顶中心 x + (cad_x − 参照刀 cad_x) × scaleX，画面 y = 参照刀顶 y + (参照刀 cad_y − cad_y) × SY。scaleX 用该室 JSON 的 `meta.scaleX`，SY = (114×98/124) / 14.6。颜色 1 是红 `#ce0c18`；ByLayer、没有颜色码、颜色 0 也当红。5 是蓝 `#2f7bff`，3 是绿 `#00e676`，6 是紫 `#d24dff`。同色、同向、中点相距不超过 22px，算这根线已经在画面上。

标注。刀的柜号来自 CAD 文字或块名，对应画面 JSON 里的文字。不要把 5A1 的 401/411/U11 套到别的室。1A1 的 K78497 没有 CAD 柜号，旁边已有「UPS维修旁」，不要补占位号。

哪些线不接。刀顶上方约 25px、CAD 没有竖线的，不拉短竖线。刀下口紫、绿、蓝空约 5.8 个 CAD 单位的留着，UPS 的紫、绿常在 18.5～29。两段母线不并成一条：2A、3A1、4A 的 U1/U2 红输出母线，5B3/5B4 上部长红线，以及 ECC1 绿母线未到 U1-Y13-1 中心。ECC 那根 (-1467.45, 8706.81)—(-1960.24, 8706.81) 不画。ByLayer、None、0 的真母线当红。ACI 4 青色不画。

竖刀同一尺寸：画面宽高来自渲染器 60×98，JSON 不写刀的 w/h。

并联组：同一前缀 -1 到 -5。CAD 只有一根竖线落到 -1 上口时，画面是 -1 处一根竖线，加一条贴刀上口的小横母线盖住组内各刀。不要给 -2 及以后从上方约 25px 的母线再拉短竖线。

变压器、进线刀、电容补偿柜：CAD 有的都要画并接到上口。变压器符号画在进线刀旁边已有的红竖线上，不画在补偿柜上。进线刀旁边没有这根红竖线的不要加变压器（1A2 的 T11-401）。CAD 没有补偿柜的室不要加柜。

`emit` 会改架构树里缺页的室，让页面能选到。已有场景页的 3A1、3A2、4B1、5A1 保留原来的 pageId。5A1 的布局文件不动。

读完网表之后，必须对照用户给的局部图，或先把这间渲染出来看过，再改已经上线、用户确认过的那一间。和用户确认过的局部图冲突时，以用户图为准。自动网表只是初稿。

## 改之前

1. 在总图上定位该室。5A1 在「5层」行最左侧；其他室自己找，不要沿用这句话。
2. 让用户看清该室全图，以及两端进线、UPS 段。没看清不要改代码。
3. 先写出该室网表：哪些端点必须通、哪些交叉必须不通、哪些刀共用小横母线。用户确认后再改该室专用布局。
4. 不要把 5A1 的柜号套到别的室。

## 5A1 已验证画法

下面的柜号只属于 5A1。其他室先对照该室 CAD，再写该室自己的布局。

实现：`ism-front-end-v2/public/hx-dcim/js/hx-5a1-layout.js`。生成：`ism-front-end-v2/public/hx-dcim/scripts/build_5a1_layout.mjs`。已验证基线见「版本号」。

### 刀

- 全部竖刀，同一尺寸 60×98。CAD 里断路器块缩放一致，额定电流不改变刀的图形大小。
- 并联或备用不是横刀纵排。一根竖线在「-1」那把刀的位置从母线挂下，接小横母线，下面挂多把竖刀。II 段镜像时，挂点仍在「-1」那把（5A1 的 421 在组的右端）。
- 只对 CAD 里确实共小横母线的那一组做并联。启发式把「一串刀」都判成并联，会把 U/Y/X 等竖刀横过来。5A1 曾这样误伤约 80 把。
- 单把刀在做并联改造之前是对的。用户明确说过：单刀的朝向、位置、接线不要改。
- 一次图上有 OUT 的刀不要加 `.hx-sym-full`。`ism-front-end-v2/public/hx-dcim/styles/hx.css` 里这条把刀片缩成宽 84%、横刀高 78%，外框一样大，看起来大小不一。刀片要满框。一次图带 OUT 用 `hx-sym-has-out`，刀片仍走满框。列头柜等非一次图画面若仍用 `.hx-sym-full`，不要顺手改掉。
- 统一成 60×98 后，铰接点会和原场景竖线错开约 20px。线必须 snap 到刀的上口、下口。只改刀框，线还挂在旧坐标上。

### 两端和顶母线

- I 段和 II 段顶母线中间断开，只经 445 母联连通。
- 两端画完整并接通：
  - 外侧变压器：三角-星，中性点接地。竖线不直接扎进红母线，出线接到进线刀下口。
  - 进线刀 401/402：母线竖线向下接到刀上口，标注总输出柜。
  - 电容补偿柜 410/420 必须画。母线落到刀上口；刀下是电流互感器、电抗、电容、接地。不要再执行「补偿柜不画」。
- 早期「上进下出」绕线和用户后来给的 401/402 局部不一致。以 `5a1-cad-t1-401*.png`、`5a1-cad-t2-402.png` 为准：母线竖线下到刀上口。

### UPS 和中部母线

- 馈线刀下口的紫线（主路）和绿线（旁路）必须连到输出刀（X01/X02）上口。不能在 UPS 名字处断开。
- 412/422 的蓝线单独落到 XBP，不并进 UPS 输出。
- 中部 U1、U2 母线是两段，不要连成一条。
- X11 → Y01 → 最底层 Y11–Y13。X12 → Y02 → 中下层 Y14–Y16。
- 左路长竖线穿过中下层母线时不相连。交叉不相连处用小拱。端点压在线上，间隙小于 2px。

## 测点

`k`、`p`、`dev` 来自场景数据，改布局时保留。CAD 有而场景没有的设备，画静态符号并标明，不要编一个测点绑上去。

## 禁止再犯

- 用启发式把一串刀都判成并联。
- 改单把刀的朝向、位置或接线。
- 给一次图的刀加 `.hx-sym-full`，或只改刀框、不把线 snap 到接线点。
- 不要再执行「补偿柜不画」。410/420 必须画。
- 回头使用已废弃的横刀纵排（`pargroup` / `horow`）。`hx-5a1-layout.js` 里横置 `orient` 就是这套旧画法。
- 只检查「401 有没有竖线」。要做整室网表：应通必通，不应通必不通，再加刀尺寸和端点压线。
- 子任务说改完了就收工。用 grep 确认版本号和函数已经落盘。
- 把 `verify_5a1_*.mjs` 放宽，用来放过别的室。新室加自己的网表检查。
- 没被要求就改 3A1、3A2、4B1 在 `verify_cad_align.mjs` 里的既有口径。
- 未等用户确认就 commit。

## 版本号

改了画面或 JSON，缓存参数要一起升，否则浏览器继续用旧脚本或旧数据。至少同时看这三处：

- `ism-front-end-v2/public/hx-dcim/index.html` 里相关 `<script src="...?v=">`
- `ism-front-end-v2/src/pages/hxDcim/HxDcimScreen.vue` 的 iframe `?v=`
- `hx-screen.js`、`hx-arch-tree.js` 里 `fetch(...?v=)`

各室一次图这一版缓存号是 `20261029bus02`，iframe、`index.html` 里 hx 的 css/js、`hx-screen.js` 和 `hx-arch-tree.js` 的 fetch 用同一个字符串。5A1 的几何仍是已验证的 `hx-5a1-cad-layout.json`，不要为了换缓存号去重画它。

- `HxDcimScreen.vue`：`/hx-dcim/index.html?v=20261029bus02#/power`
- `hx-screen.js`：`hx-power-page-index.json`、`hx-scenes.json`，以及 `HX5A1.load` / `HXRooms.load`
- `hx-arch-tree.js`：`hx-arch-tree.json`
- 其他室布局：`hx-power-rooms/index.json` 和每间 json，`?v=20261029bus02`。`read_cad_power_room.py` 的 `VERSION` 与此相同。只重写某几间时用 `emit-codes`，不要靠全量 `emit` 把其余室一起刷掉。1A1 在生成时把两块中心距收到约 96px，并且整段平移，不能只挪一根线的一端。

不要再把 `e` / `f` / `j` 混在同一次改动里。改了画面或 JSON，这些 `?v=` 一起升。

改完 grep 这些 `?v=`，并确认布局函数在对应的布局文件里。
