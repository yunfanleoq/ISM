# 修复 CAD 再出一次图和 CAD 原图

刀下竖线整排停在铭牌上沿前面，源图里这根馈线就没接到框。这种缝不要在一次图 JSON 上逐段补。先读源 CAD 的组和码，把该接上的接到铭牌近边，把多余短头剪掉，写成一份新的 CAD，再从这份新文件生成一次图和 CAD 原图。

总入口仍是 `cad-read-draw`。一次图的刀、颜色、互感器以 `ism-hx-power-oneline` 为准。本页只规定修复文件怎么写、两张图从哪份文件来。

## 源文件用用户给出的 DXF（2026-11-10）

配电室原图以用户给出的 DXF 为源。不要再跑 `dwg2dxf`，也不要为了出图去改 DWG。

LibreDWG 转出来的 DXF 只是旧链路的中间文件，不能当成用户没给 DXF 时的替代源去重转。

CAD 原图和一次图仍共用同一个坐标变换：读 DXF 组码，CAD 原图只做 Y 取反，一次图用该房间代码里的 scale 和 PAD。不要再套口头的 S=12、PAD=40，除非该房间代码确实是这个数。2A2 实测是 scale 34.0531、PAD 100。

一次图仍要做技能里已有的简化：刀闸用共享符号、去掉电流互感器、去掉长约 7.37 的横担、短缝补上。这些简化不能写回 DXF。

通用 DXF→JSON 只适合当原样实体的中间格式，不能直接变成一次图 JSON。

## 一次图不再补线拼缝（2026-11-10）

一次图不再补线、拼缝。它和 SVG 用同一次展开、同一套变换，DXF 里的线、端点、缺口原样留下。旧的「短缝拉到铭牌/母线」不要再用在一次图上。和 SVG 只允许两处不同：铡刀换成共享符号（长轴 140px，刀口方向跟 SVG 一致），电流互感器不画。断开的母线不要接成一根。这些差别不能写回 DXF，也不能写回 SVG。详见 `ism-hx-power-oneline`「一次图不再补线拼缝」。

## 文件

1. 源 DWG 只读。`docs/refs` 里的单室 DWG、`5A1-新.dwg`、两份 `配电系统图.dwg` 都不改字节。不要改全局 `cad_dxf.py`。
2. `dwg2dxf` 写到 `/tmp`。整份未修复的 DXF 不入库。
3. 修复结果写到 `docs/refs/hangxin-screen-drawings/repaired/<房间>-fixed.dxf`。这是新文件。同名已有时覆盖的是这份修复稿，不是源 DWG。
4. 一次图 JSON 和 `public/hx-dcim/cad/<房间>.svg` 都从这份 `-fixed.dxf` 生成。不要一边用源 DWG 画 CAD 原图，一边用另一套补线画一次图。
5. 已经认可、用户没有点名要改的房间，不要重跑修复，也不要覆盖它的 CAD 原图 SVG。

## 读

用仓库里的组码解析读 `/tmp` 的 DXF。线、多段线、文字、块插入都要展开到模型坐标。字号只用每条文字的第一条组码 40。铭牌位置用文字插入点（组码 11/21）。截图、看图软件当前画面不能当要改哪根线的坐标。

先分出三类东西，再动笔：

| 类 | 怎么认 | 修复稿里怎么处理 |
|---|---|---|
| 朝铭牌去的馈线 | 自由端对着某块铭牌的近边，中间没有别的设备 | 短了收到近边，穿进框的收到近边 |
| 母线、联动杆、不是朝铭牌的立管 | 沿排成一路，或不指向任何铭牌 | 不伸长，不拉进框 |
| 多余短头 | 过了接头、刀端子或铭牌边还往空处伸出，另一头不接刀、不接母线（含多段线）、不接铭牌 | 从修复稿删掉 |

## 接到铭牌

横线从左来停在左沿，从右来停在右沿。竖线从上来停在上沿，从下来停在下沿。只改这一端，另一端留在刀端子或母线上。框的坐标不动，字不动。

同一排刀下都空着一截时，整排一起收到各自铭牌的上沿。不要只接画面上那一根。框下面已经从下沿离开、接到下一根母线的线，保持从下沿起笔，不要拉上去和上面的馈线接成一笔。

不许穿过文字，不许在框里打缺口，不许从另一侧穿出。源图在铭牌另一侧确实还有一段接到别的设备时，修复稿里分成两段：一侧停在近边，另一侧从对边重新起笔。源图在框前就停了、另一侧没有设备，就只收到近边，另一侧不补线。

不要把母线、联动杆、房间立管拉到铭牌上。不要把两段分开的母线接成一条。源图没有指向这块铭牌的线，不要发明一根。

## 剪掉多余

连线止于接头、刀端子或铭牌边。过了接头还冒出去的一段，剪到接头上。不接到刀、母线或铭牌的短头从修复稿删掉。接头上的圆是接通，没有圆的交叉仍是交叉，不要接上，也不要删掉那两根交叉线。

删短头之前先认连接，不能只看 LINE 的端点：

- 刀是块插入（`DYDQ0201`、`DYDQAA03`、`DYDQAA04`、`DYDQAA05`、`DYDQAA09`）。引线停在插入点上，旁边没有另一根线的端点。这是母线到刀的连接，留着。
- 母线经常是 `LWPOLYLINE`，不是 `LINE`。短竖线一头在刀上，另一头离多段线母线不到半个绘图单位，画面上已经连上。留着，不要整段删掉。

删完用源图对修复稿。母线到刀的竖线还在，才算剪对。

该连续的母线不要因为剪短头而断开。朝铭牌去、只是还差一截的馈线是要接上的线，不是多余线，不要删。

## 留在修复稿里、一次图再丢掉

电流互感器（块 `A$C03DD39B5`，导体上一个或并排几个小圆）留在 `-fixed.dxf` 里。CAD 原图照修复稿画出这些圆。生成一次图时不画圆，导体仍是一根，不留缺口、不留短头。

刀块（`DYDQ0201` 以及 `DYDQAA03` / `DYDQAA04` / `DYDQAA05` / `DYDQAA09`）留在修复稿里。CAD 原图展开刀片、铰接、触头。一次图只用现有刀符号，一把刀一种状态，不把闭合直线和打开刀弧叠上，也不把块里的斜刀、箭头、叉再描一遍。

这两类不是多余短头。不要为了一次图干净，从 `-fixed.dxf` 里删掉。

## 写出之后

1. 用 `-fixed.dxf` 生成该室 CAD 原图 SVG。
2. 用同一份 `-fixed.dxf` 生成一次图 JSON。一次图刀长轴、出线色、不画互感器，仍按 `ism-hx-power-oneline`。
3. 打开 CAD 原图 svg，再对一次图。对的是这份修复稿画出来的原图：哪根线落到哪块铭牌、哪根线停在框边、哪段母线仍然分开。对不上就改一次图，不要再回到源 DWG 把刚接上的线缩回去。
4. 源 DWG 的 MD5 与动手前相同。`配电系统图.dwg` 的 MD5 仍是 `c58f0fb1dfacc088b8f6f470ffd2b6d5`。

## 踩过的坑：母线到刀被当成短头删掉

错法：剪短头时只问「这端有没有另一根 LINE」。4B2 上排刀到母线的短竖线，下端停在刀块插入点，上端离多段线母线大约 0.1 个绘图单位。脚本看不见刀端子，也不把多段线当母线，上端就成了悬空，下端又落在刀自己的横线上，整段被删。这一轮删了 60 段，其中 54 段是这种引线。修复稿里母线和刀断开，源图里是连着的。

改法：连接要同时认 LINE、多段线母线、刀块插入点。一端在刀的插入点上，或离多段线母线不到半个绘图单位，这根线留下。真正的短头是过了接头还往空处冒、并且不接刀、不接母线、不接铭牌的那一段。删完先对源图，母线到刀的竖线必须还在。4B2 上排是例子，别的房间同样处理。

## 2A2 红框里的缝

2026-11-09。源 `2A2.dwg` 的 MD5 仍是 `a48fe0c289fe48c775a2a0d388da31bf`。修复稿是 `docs/refs/hangxin-screen-drawings/repaired/2A2-fixed.dxf`。一次图 `hx-power-rooms/2A2.json` 和 CAD 原图 `cad/2A2.svg` 都从这份修复稿出，只重出这一间。

错法：把刀身大约 50px 的缝、铭牌高度大约 118px 的缝、变压器圆左右被圆断开的竖线，当成母线断口接上。把 Y11 列尾和 Y14 列头两根立管之间的横线拉到两边立管上，两段母线就并成一根。

改法：朝铭牌的馈线收到铭牌近边（这一间修复稿收了 97 处），过了接头的短头剪掉。刀身、铭牌框、变压器圆上的缝不接。两根分开的立管不并成一根。电流互感器留在修复稿和 CAD 原图里，一次图不画。一次图刀闸共享符号长轴仍是 140px。不要整层四间一起重出。

## 原样复刻只用一个变换（2026-11-10，2A2 实测）

错法：用口头的 S=12、PAD=40 去对二层一次图，或把 SVG 里已经取反的 y 和一次图屏幕坐标直接相减。数字对不上，就像母线、铭牌、柜位各偏一截。

实测源是 `/tmp/hx-2a2-downloads.dxf`（与 `floor2-20261107/2A2.dwg` 同一份，MD5 `a48fe0c289fe48c775a2a0d388da31bf`）。`cad_room_svg.py` 只做一次变换：svg x = 组码 x，svg y = −组码 y。模型和 LibreDWG `dwg2SVG` 的模型空间线段对齐后，残差在 1e-6 个绘图单位。块基点全是 0。文字锚点用对齐点（TEXT 组码 11/21，MTEXT 组码 10/20），不是再平移一截。

一次图用同一批展开坐标，不是另一套缩放：

x' = (x − minx) × 34.0531 + 100

y' = (maxy − y) × 34.0531 + 100

2A2 的 minx = 50.6907，maxy = 297.1846。scale 来自刀长 1.4903，PAD 是 100。110 块铭牌框角点对 DXF 矩形，最大差 0.027px。绿母线两端、竖干线、`DYDQ0201` 插入点、`2A2-T2-402` 对齐点、`东侧测试母线` 插入点、模型圆，逆变换后都在 0.02px 以内。东侧测试母线（y=191.13）和东侧备份母线（y=102.80）仍是两根。

改法：柜位、母线、铭牌只走这一个变换。允许的改动仍只有接短缝、去掉 7.37 横担、刀闸换共享符号（长轴 140px）。不要改成 S=12。不要为了对齐数字再挪端点。CAD 原图 SVG 的线、字、块插入由组码直接做这一次 Y 取反，不要在 `write_svg` 里再吸附端点。

## 先画对 DXF→SVG，再画一次图（2026-11-10，2A2-T1-411）

用户说连接线突出时，先分开量左端相对母线、右端相对铭牌。不能沿用上一次「线伸出铭牌右边」。2A2-T1-411-1～5 是穿过左侧竖母线，伸到母线左边；铭牌右缘没有被穿过。刀口要单独核对上下。

错在块展开：插入要先缩放再旋转。先旋转再乘 sx、sy，会在 ang=90 且 sx、sy 正负不同时把刀口上下翻掉，并把刀轴翻到母线左侧。整图 Y 取反只做一次。块局部坐标不要再反一次，也不要漏反。左右不要跟着对调。

顺序：先把 DXF→SVG 画到和 DXF 一致，一次图再参考这张 SVG。不要一边改一次图一边改 SVG。细节和实测数见 `ism-hx-power-oneline`「连接线突出要分左右量，块先缩放再旋转」。

同一列横刀铰接不齐，不是包围盒变了，也不是要改 SVG。`source_bus_x` 把铰接吸到长度 ≥ 8 的竖母线上，短于 8 的那段就退回插入点或吸到旁边另一根母线。铰接放在块展开后的轴线端点。见 `ism-hx-power-oneline`「横刀铰接被吸到不同母线」。

换符号之后块外缺的那截，不能靠再吸母线来补，也不能 100 把刀补同一方向。竖刀上端有的是短竖线、有的是短横，下端是馈线；横刀铰接端已经贴着短头的不要再加。只补到这把刀在 SVG/DXF 里块外那根线的近端。见 `ism-hx-power-oneline`「换符号后缺线要按每把刀的端点补」。

横刀轴线要和左右进出线同一高度。绿弧浮在线上方是分闸张开，不是刀轴下移，不要为此改 SVG 或移轴。2A2 的 U1-Y11-1 模型 Y 是 208.368，画面 Y 约 4162.7，红线和绿线只差 0.26 像素。见 `ism-hx-power-oneline`「横刀轴线和进出线同一高度」。已接受的 `cad/2A2.svg`（MD5 `d346ebe4e3548ec61b8043aa3abef388`）和用户 DXF `/Users/yunfanleo/Downloads/2A2.dxf`（MD5 `69b22a01c0c8ec4ef9f36f2766faf788`）不要覆盖，也不要另跑 `dwg2dxf`。
